# 01. 概念とユースケース

[インデックスへ戻る](./index.md)

---

## 1. 全体概要
本システムは、中央サーバーを必要とせず、同一ローカルエリアネットワーク (LAN) 内に存在する端末同士が直接通信（P2P）することで、プロジェクトの進捗・タスク状態・アクティビティを共有・管理するためのツールです。

**「Local-First（ローカルファースト）」** 設計思想、**「Obsidian型ノードグラフ表示 (Obsidian-like Graph View)」**、および **「Gitライクな追跡ログ (JSONL Append-Only Log)」** を採用しており、美しい視覚的ノードネットワークと爆速操作を実現します。

---

## 2. 3つの表示モードとObsidian型グラフィカルキャンバス

本ツールでは、複雑な項目入力を廃止したミニマル設計を基礎とし、用途に合わせた **3つのビジュアル表現モード** を提供します。

```
+---------------------------------------------------------------------------------+
|                    Obsidian型 3大ビジュアル表現モード                           |
+---------------------------------------------------------------------------------+
                                         |
     +-----------------------------------+-----------------------------------+
     |                                   |                                   |
     v                                   v                                   v
【1. 樹状ツリービュー (Tree View)】  【2. Obsidian型グラフビュー (Graph)】 【3. カンバンビュー (Kanban)】
・TODO/PROGRESS/DONEの区分けを排除  ・暗闇に浮かぶノードネットワーク    ・従来の 3カラムレイアウト
・単一キャンバス上で純粋なツリー表示  ・ノード間の美しい光る接続線      ・ステータス一括確認
・全階層ステータスバッジ+進捗率バー ・一定時間無操作で自動イマーシブ移行
```

### (1) 樹状ツリービュー (Pure Tree View)
- **カラム分割の排除**: ツリー表示時は TODO / PROGRESS / DONE の 3カラム区分けを廃止し、**単一キャンバス上で純粋な親・子・孫の樹状構造** として美しく描画します。
- **全階層ステータス制御**: どのノードにも `[TODO]` `[PROGRESS]` `[DONE]` の色付きバッジが表示され、1クリックで状態を変更できます。
- **親進捗率表示**: 親ノードには「進捗率 (例: 2/3 完了 66%)」プログレスバーを表示。

### (2) Obsidian型グラフビュー (Obsidian-like Graph / Canvas View)
- **ノードネットワーク表現**: ノード同士が網の目のように光るラインで連結された Obsidian グラフビュー風のビジュアル。
- **無操作自動トランジション (Idle Auto-Transition)**: 一定時間（例: 3〜5秒）キーボードやマウス操作がなかった場合、自動的に Obsidian型グラフ表示へイマーシブ遷移し、プロジェクト全体の繋がりを鑑賞・俯瞰できます。

### (3) カンバンビュー (Kanban View)
- TODO / IN_PROGRESS / DONE の 3カラム分割による従来型の進捗一括管理。

---

## 3. 解決する課題
- **区分けカラムによるツリーの分断を防止**: カラム枠を取り払い、純粋な樹状ツリーとして一覧。
- **プロジェクト全景の没入的俯瞰**: 無操作時に Obsidian 型ノードグラフへ自動移行し、脳内にプロジェクトの全体像を直感インプット。
- **履歴追跡とポータビリティ**: Gitのような全履歴ログを JSONL ファイル1本でポータブルに保管・移動可能。

---

## 4. 拡張性を担保する原則
- **ローカル優先・非同期伝播**: 変更は常にローカルの `.jsonl` ファイルへ即座に記録し、P2Pネットワークへは非同期で波及させる。
- **トランスポート透過性**: P2P 通信が UDP/TCP/WebSockets/WebRTC のいずれであっても、進行管理のドメインロジックに影響を与えない設計とする。
- **UI 非依存**: CLI、純粋ツリービュー、Obsidianグラフキャンバス、カンバンビュー等のいずれにも移植できる構造とする。
