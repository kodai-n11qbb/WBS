# Share-Log プロジェクト仕様ドキュメント インデックス

本ドキュメント群は、分散・ローカルファーストタスク管理システム **「Share-Log」** の概念、システムアーキテクチャ、データモデル、同期仕様、および拡張設計を定義する技術仕様書です。
開発方針については [`../DEV_POLICY_v1.0518.md`](../DEV_POLICY_v1.0518.md) を厳守します。

---

## ドキュメント構成

1. [01. 概念とユースケース](./01_concept.md)
   - 本システムのコアコンセプト、Obsidian型ノードグラフ前面配置、GanttProjectスタイルガントチャート、完了予定日 (`dueDate`) 3ヶ月スケール、Enter/Esc操作連携、動作モード（P2P / CLIENT / HOST）、解決する課題
2. [02. システムアーキテクチャ抽象](./02_architecture.md)
   - Hexagonal / Clean Architecture に基づくレイヤー構造とコンポーネントポート定義、DI（依存性注入）方針、スタンドアロン単一バイナリ構造
3. [03. データモデルと同期仕様](./03_data_sync.md)
   - ミニマルタスクエンティティ、`data/state.json` スナップショット仕様、`config.json` スキーマ、対話型セットアップCLI、イベントログ同期 (`events.jsonl`) メカニズム
4. [04. 拡張性およびプラグイン設計](./04_extension_spec.md)
   - 単一バイナリ配布パッケージング、対話型セットアップ、通信・ストレージアダプター拡張ポイント、相対パス保守ルール

## 仕様の変更履歴

- **v1.3.0 (2026-09-22)**:
  - 画面仕様を **グラフ ＆ ガント の 2ビュー構成** に特化。
  - 親タスク設定確認ダイアログでの **Enter（確定）/ Esc（キャンセル）** キーボードショートカット操作に対応。
  - 表記を「**完了予定日**」に統一。
  - 初回デモサンプルデータを3ヶ月（90日）スケールに拡張し、ガントチャートで一番遠い完了予定日 (`dueDate`) を自動判定してタイムライン右端内に納める Auto-Fit スケール描画を導入。
- **v1.2.0 (2026-09-22)**:
  - Linear / Raycast スタイルテキストデザインシステム（Dark/Lightモード）を導入。
  - Obsidian Node Inspector およびキャンバス内最上部ルート化ドロップゾーンを追加。
  - 不変イベントログからの不完全作業期間プロット型ガントチャートを導入。
- **v1.1.0 (2026-09-22)**:
  - 3つの動作モード（P2P / CLIENT / HOST）と `config.json` スキーマ仕様を追加。
  - ディレクトリ直下への最新状態スナップショット (`data/state.json`) 保存仕様を策定。
- **v1.0.0 (2026-09-20)**:
  - ローカルファースト P2P タスク同期ツールの基本仕様を策定。
