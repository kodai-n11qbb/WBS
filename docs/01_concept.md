# 01. 概念とユースケース

[インデックスへ戻る](./index.md)

## 1. 全体概要
本システムは、中央サーバーを必要としない対等な **分散モード (P2P)**、指定ホストに接続する **クライアントモード (CLIENT)**、および自端末で接続を受け付ける **ホストモード (HOST)** の3つの柔軟な運用形態に対応した、プロジェクト進行管理ツールです。

**「Local-First（ローカルファースト）」** 本ツールでは、全体の構造化と「全体像が見えること」を最優先とし、**Obsidian型ノードグラフ表示を主軸（前面）**に配置した全画面キャンバスを基礎とします。絵文字や過剰なグラデーション、Blob背景アニメーションを排し、エンジニアリング重視の静かで高コントラストなテキスト主体デザインシステム（Dark / Light モード対応）を提供します。

```
+-----------------------------------------------------------------------------------------+
| [Share-Log] [Node: dev-1]   [ グラフ | ツリー | カンバン | ガント ]   [ ダーク/ライト ]    |
+-----------------------------------------------------------------------------------------+
| [ ここにドラッグでルート要素化 ] (ドラッグ時に出現する共通ルート化ドロップゾーン)               |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|      (親ノード) ← 画面上部へ配置 (Y軸重力)                                              |
|          ◯                                                                              |
|         / \                                                                             |
|        ◯   ◯ (ノードクリック → クイックインスペクター表示)                                |
|             │   ┌──────────────────────────────────────────────┐                         |
|             └──>│ [タイトル編集 (Enter)] [TODO/進行中/完了] [ルート化] │ (ノード操作)     |
|                 └──────────────────────────────────────────────┘                         |
|                                                            [画面端 ネスト表示切替]      |
|                                                            | 1階層 | 2階層 | すべて |    |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
|                      画面下部固定 タスク追加プロンプトバー                               |
|  [ ルートタスク ▾ ]  タスク名を入力してEnter...                             [ 作成 ]    |
+-----------------------------------------------------------------------------------------+
```

### (1) 前面化された Obsidian型 物理グラフィカルキャンバス (Obsidian Graph View)
- **前面メイン画面化**: アプリの標準画面としてグラフキャンバスを前面に配置。
- **実用重視のテキスト・モノトーンデザイン**: 絵文字やド派手なエフェクトを廃し、Linear / Raycast 風のクリーンなグリッドとソリッド境界線を採用。
- **ノードクリック・クイックインスペクター (Obsidian Node Inspector)**:
  - キャンバス上のノードをクリックすると、ノード近傍に**インスペクター・ツールバー**を表示。
  - **インラインタイトル編集**: タイトルを即座にテキスト編集して Enter/Save で保存 (`TASK_TITLE_UPDATED`)。
  - **ワンタップ進行度変更**: `[ TODO ] [ 進行中 ] [ 完了 ]` ボタンで瞬時にステータス切り替え (`TASK_STATUS_UPDATED`)。
  - **1クリック ルート昇格**: `[ ルート化 ]` ボタンで親タスクから切り離し (`TASK_PARENT_CHANGED`)。
- **階層に応じた自然な上下配置（Y軸重力・垂直バイアス）**:
  - 構造の上位（親・祖先ノード）であるほど、自然と画面上部へ移動・漂う物理挙動。
  - 子・孫ノードは親ノードの下方向へ自然にぶら下がるため、全体の上下関係と構造が一目で把握可能。

### (2) 共通化された子要素のルート要素化メカニズム (Unified Subtask-to-Root Elevation)
Obsidianグラフ、ツリー表示、カンバン表示の全ビューで一貫した操作感で子タスクをルート階層 (`parentId: null`) へ移動可能：
1. **ノード/カード クイック操作ボタン**: インスペクターやカードの `[ ⇡ ルート化 ]` ボタンを押す。
2. **共通ヘッダードロップエリア**: どのビューでもドラッグを開始すると画面上部に `[ ⇡ ここにドラッグでルートタスク化 ]` エリアが出現し、そこにドロップするだけでルート化。

### (3) イベントログ連携 ガントチャート表示 (Gantt Chart Timeline View)
- ビュー切替ボタン `[ 📊 ガント ]` により、`events.jsonl` の時系列ログから自動生成されたタイムラインビューへ切り替え。
- **時間軸可視化**: タスク生成時刻 (`TASK_CREATED`) から着手・完了時刻 (`TASK_STATUS_UPDATED`) までの作業期間を横軸タイムラインバーでプロット。
- **実績とステータスの把握**: 各タスクの所要時間（例: `35分間`）や現ステータスを時系列で俯瞰。

### (4) 画面端のネスト表示深度調整 (Screen Edge Nesting Depth Control)
- 画面端に配置されたシンプルで視認性の高い深度切り替えコントローラー（1階層 / 2階層 / 3階層 / すべて）。

### (5) クリーンなヘッダー ＆ テーマ切替 (Clean Header & Theme Switcher)
- 最小限のタイトル、ノード接続状態、4つのビュー切替 (`グラフ`, `ツリー`, `カンバン`, `ガント`)、およびダーク / ライトテーマ切替ボタン `[ 🌙 / ☀️ ]` を配置。

## 3. ディレクトリ直下の最新状態スナップショット運用 (`data/state.json`) ＆ 動作モード
- **最新状態スナップショット (`data/state.json`)**:
  - タスクの追加・変更・削除のたびに、指定ディレクトリ内の `data/state.json` に最新の全タスク状態（Materialized Snapshot）がリアルタイム自動保存されます。
- **動作モードとアドレス設定**:
  - **`P2P` (分散モード)**: 共有データのアドレス（`data/state.json` のパス）を指定して分散動作。
  - **`CLIENT` (クライアントモード)**: 接続先ホストの端末アドレス（IP/ポート）を指定して接続。
  - **`HOST` (ホストモード)**: 自身を親機として起動しクライアント接続を受付。

---

## 4. 解決する課題
- **全体像と構造化の可視性**: 全体が俯瞰できる前面グラフビュー、ツリー、カンバン、時系列ガントチャートにより、多角的にタスクの繋がりと進捗状況を把握。
- **直感的なノード編集**: キャンバス上のノード直接クリックからタイトル編集・ステータス変更・ルート化を完結。
- **洗練された視覚デザイン**: 静かで集中できる Linear/Raycast スタイルの高コントラスト UI とダーク/ライトモード対応。
- **柔軟な運用形態**: 分散P2P・クライアント接続・ホスト運用の3モードを自由に切り替え。

---

## 5. 拡張性を担保する原則
- **ローカル優先・非同期伝播**: 変更は常にローカルの `data/state.json` および `.jsonl` ファイルへ即座に記録し、P2Pネットワークへは非同期で波及させる。
- **UI 非依存 Core**: Obsidianグラフキャンバス、ツリー、カンバン、ガントチャートのいずれにも移植できるモジュール構造とする。
