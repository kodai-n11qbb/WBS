## 1. 画面基本レイアウト

WBSer は、全画面を最大限に活用した Obsidian型物理グラフキャンバスをメイン画面とし、必要に応じて GanttProjectスタイルガントチャートへワンクリックで切り替えられる 2画面構成となっています。

```
+-----------------------------------------------------------------------------------------+
| [WBSer] [Node: dev-1]   [ ↺ 1つ戻す (Undo) ]   [ グラフ | ガント ]   [ ダーク/ライト ]  |
+-----------------------------------------------------------------------------------------+
| ┌───────────────────────────────┐               ┌─────────────────────────────────────┐ |
| │ ← 親要素へ移動: [親タスク名]  │               │ [ネスト: 1階層 | 2階層 | すべて]     │ |
| └───────────────────────────────┘               │ [表示日数: 7日 | 14日 | 30日 | 60日] │ |
| (専用上部ツールバー: .graph-top-toolbar)        │ [文字サイズ: 小 | 中 | 大]           │ |
|                                                 └─────────────────────────────────────┘ |
+-----------------------------------------------------------------------------------------+
| [ 📅 期日未設定 ] [ ◀ 過去 ] [ 今日 10/17 ── +7日 ── +14日 ── +30日 ] [ 未来 ▶ ]       |
|    (Zone 1)        (Zone 2)                (メインタイムライン)         (Zone 4)        |
|       ◯ (未設定)       ◯ (過去)        ◯ (同日タスクA)                                  |
|        : (波線Bézier)   : (波線Bézier)  │ (同一X座標に縦積み・54px間隔保証)             |
|        :                :              ◯ (同日タスクB)                                  |
|                                                                                         |
|       ┌────────────────────────────────────────────────────────┐                        |
|       │ [タイトル編集] [完了予定日:YYYY-MM-DD] [TODO/進行中/完了] [ルート化] [タスク削除]   │   |
|       └────────────────────────────────────────────────────────┘                        |
+-----------------------------------------------------------------------------------------+
|                      画面下部固定 タスク追加プロンプトバー                               |
|  [ ルートタスク ▾ ]  タスク名を入力してEnter...                             [ 作成 ]    |
+-----------------------------------------------------------------------------------------+
```

## 2. 主要コンポーネント配置

### (1) ミニマルヘッダーバー (`.app-header.minimal-header`)
- **左側エリア**:
  - `project-title`: プロジェクト名（WBSer）
  - `node-pill`: 自端末の接続状態およびノード名（`Node: dev-node-1`）
- **右側エリア**:
  - `btn-undo`: 自端末の直前操作を取り消す `[ ↺ 1つ戻す ]` ボタン
  - `view-switcher-group`: `[ グラフ ]` / `[ ガント ]` 表示切替ボタングループ
  - `btn-theme-toggle`: ダーク / ライトモード切り替えボタン

### (2) グラフ上部専用ツールバー (`.graph-top-toolbar`)
- `#obsidian-graph-view` 最上部に常設された専用バー（Flexbox構造）。キャンバス領域（`.canvas-wrapper`）と完全に分離されているため、日付バーやノードの視界を一切遮らない。
- **左端エリア (`#graph-parent-nav`)**:
  - サブタスク選択時に `← 親要素へ移動: [親タスク名]` ボタンを表示。
  - 親ノードへ視点を瞬時に移動・フォーカス可能。
- **右端エリア (`#depth-filter-control`)**:
  - **ネスト表示切替**:
    - 全体表示時: ルート起点の階層深度（1階層 / 2階層 / 3階層 / すべて）。
    - 要素選択時: **クリックされた要素を起点とした相対階層絞り込み**（選択要素自身＋直下1階層 / 2階層 / 3階層 / すべて）。
  - **表示日数切替（要素選択時アクティブ）**:
    - タイムライン日数設定ボタン（`[ 7日 ] [ 14日 ] [ 30日 ] [ 60日 ]`）。
  - **文字サイズ切替**: 小 / 中 / 大。

### (3) キャンバス内ルート化ドロップゾーン (`#root-dropzone`)
- キャンバス上部（`Y <= 60px`）に配置されるガイド領域。
- ノードをドラッグしてこの領域にドロップすると、親タスクとの親子関係が解除され、ルートタスクへと昇格。

### (4) 詳細インスペクターパネル (`.task-inspector-drawer`)
- グラフ上のタスクをクリックした際に開くドロワーパネル。
- タイトル編集、ステータス変更（TODO / 進行中 / 完了）、完了予定日ピッカー、優先度、ルート化ボタン、削除ボタンを配置。
- **インスペクターシールド**: パネル展開時、背後のノードやラベルが透けたり文字が重なったりしないよう、反発力場とソリッド背景・Z-index保護を適用。

### (5) 要素選択時 日付軸タイムライン ＆ 4ゾーン配置
- **日付軸の描画**: 要素クリック時、キャンバス上部に「今日（Today）」を起点とする日付目盛り軸を描画。
- **ゾーン別レイアウト**:
  - **Zone 1: 📅 期日未設定ゾーン（左端）**: 完了予定日（`dueDate`）が設定されていないタスクを専用枠内に整列配置。
  - **Zone 2: ◀ 過去ゾーン**: 完了予定日が今日より前（過去）のタスクを専用枠内に配置し、「`[10/15 過去]`」バッジで明示（遅延とは断定せず過去として中立表示）。
  - **Zone 3: メインタイムライン（今日〜今日+N日）**: 期間内のタスクを各完了予定日に応じてX座標へ配置。
  - **Zone 4: 未来 ▶ ゾーン（右端）**: 選択中の表示日数を超える遠い未来のタスクを右端枠内に集約し、「`[11/15 未来]`」バッジで明示。
- **同日タスクの厳格な同一X軸整列 ＆ 縦積み重なり防止**:
  - 同一完了予定日を持つタスク群は、水平オフセット（ジッター）を生じさせず **完全に同一のX座標** に垂直配置。
  - 垂直方向は深さ（階層順）および兄弟インデックスに応じて `54px` の縦オフセットを厳格保証し、物理反発力（最小Y距離 `56px`）によって文字ラベルの重なりを完全防止。
- **通常グラフ表示時の兄弟要素文字重なり防止**:
  - Sugiyama階層アルゴリズムにおいて、同一深さのタスク間に `135px` 以上の水平距離を強制設定。
  - 物理シミュレーションにおけるラベル反発係数を強化（`0.75`）し、兄弟要素のタイトルテキストが重ならないクリアな視認性を確保。
- **クロスゾーン接続ライン（波線Bézier曲線）**:
  - Zone 1（未設定）および Zone 2（過去）とタイムライン内タスクを結ぶ接続線は、強烈な直線ではなく、柔らかな半透明アンバーの点線 Bézier曲線（`rgba(245, 158, 11, 0.45)`, `[5, 4]`）で描画。
- **ドラッグ＆ドロップによる完了予定日直感変更**:
  - ノードを横ドラッグして日付列上にドロップすると、確認ダイアログ（「完了予定日を変更しますか？」）が表示され、Enterで確定、Escでキャンセル。
  - 左端の「📅 期日未設定」ゾーンにドロップすると、期日を未設定（`null`）にリセットする確認ダイアログを表示。
- **背面ノードの誤結合防止**:
  - 背景に薄く表示されている非選択ノードへのドロップによる親子結合は無効化し、意図しないツリー破壊を防止。
- **キャンバス横スクロール/ドラッグ（Pan）**: キャンバス背景をドラッグ操作することで、過去や未来の期間外日付へも自在に横スクロールして見渡すことが可能。
- **非選択ノードの背景Dim表示**: 選択ツリー以外のノード群は半透明（Dim表示）として背景に維持され、プロジェクト全体の文脈を見失わない。

### (7) ガントチャートコンテナ (`#gantt-view-container`)
- **ヘッダー軸 (`.gantt-ticks-header`)**: 日付目盛りを等幅グリッドで表示。
- **バーセル (`.gantt-bar-cell`)**: 上部ヘッダーと完全に一致するピクセル幅で同期し、横ズレのない正確なタイムラインを形成。
- **超過ハイライト ＆ 遅延バッジ**: 親タスクの完了予定日を超過した子タスク期間を赤色グラデーションで強調し、「`+N日遅延`」バッジを付与。

### (8) 下部固定 タスク追加プロンプトバー (`.task-input-section`)
- 画面最下部に固定配置された入力フォーム。
- 親タスクのドロップダウン選択、タスク名テキスト入力、Enterキーでの即時追加をサポート。
