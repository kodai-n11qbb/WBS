## 1. 画面基本レイアウト

WBSer は、全画面を最大限に活用した Obsidian型物理グラフキャンバスをメイン画面とし、必要に応じて GanttProjectスタイルガントチャートへワンクリックで切り替えられる 2画面構成となっています。

```
+-----------------------------------------------------------------------------------------+
| [WBSer] [Node: dev-1]   [ ↺ 1つ戻す (Undo) ]   [ グラフ | ガント ]   [ ダーク/ライト ]  |
+-----------------------------------------------------------------------------------------+
|  ┌─────────────────────────────────┐                                                    |
|  │ ← 親要素へ移動: [親タスク名]    │ (.graph-parent-nav: 左上固定親ナビゲーションUI)   |
|  └─────────────────────────────────┘                                                    |
|                                                                                         |
|      (親ノード) ← 上方向親リンク視覚表示 (ノードクリックで最上部浮上・配下全展開)         |
|          ◯                                                                              |
|         / \                                                                             |
|        ◯   ◯ (ノードクリック → 最上部へ焦点移動 ＆ 配下全子要素展開 ＆ サブツリー強調)   |
```

## 2. 主要コンポーネント配置

### (1) ミニマルヘッダーバー (`.app-header.minimal-header`)
- **左側エリア**:
  - `project-title`: プロジェクト名（WBSer）
  - `node-pill`: 自端末の接続状態およびノード名（`Node: dev-node-1`）
- **右側エリア**:
  - `btn-undo`: 自端末の直前操作を取り消す `[ ↺ 1つ戻す ]` ボタン
  - `view-switcher-group`: `[ グラフ ]` / `[ ガント ]` 表示切替ボタングループ
  - `btn-theme-toggle`: ダーク / ライトモード切り替えボタン

### (2) 親ナビゲーションUI (`.graph-parent-nav`)
- グラフキャンバス左上に `position: absolute; top: 16px; left: 16px;` で固定配置。
- サブタスクを選択している際、`← 親要素へ移動: [親タスク名]` ボタンを表示。
- 親ノードへ視点を瞬時に移動・フォーカスさせることが可能。

### (3) キャンバス内ルート化ドロップゾーン (`#root-dropzone`)
- キャンバス上部（`Y <= 60px`）に配置されるガイド領域。
- ノードをドラッグしてこの領域にドロップすると、親タスクとの親子関係が解除され、ルートタスクへと昇格。

### (4) 詳細インスペクターパネル (`.task-inspector-drawer`)
- グラフ上のタスクをクリックした際に開くドロワーパネル。
- タイトル編集、ステータス変更（TODO / 進行中 / 完了）、完了予定日ピッカー、優先度、ルート化ボタン、削除ボタンを配置。
- **インスペクターシールド**: パネル展開時、背後のノードやラベルが透けたり文字が重なったりしないよう、反発力場とソリッド背景・Z-index保護を適用。

### (5) ガントチャートコンテナ (`#gantt-view-container`)
- **ヘッダー軸 (`.gantt-ticks-header`)**: 日付目盛りを等幅グリッドで表示。
- **バーセル (`.gantt-bar-cell`)**: 上部ヘッダーと完全に一致するピクセル幅で同期し、横ズレのない正確なタイムラインを形成。
- **超過ハイライト ＆ 遅延バッジ**: 親タスクの完了予定日を超過した子タスク期間を赤色グラデーションで強調し、「`+N日遅延`」バッジを付与。

### (6) 下部固定 タスク追加プロンプトバー (`.task-input-section`)
- 画面最下部に固定配置された入力フォーム。
- 親タスクのドロップダウン選択、タスク名テキスト入力、Enterキーでの即時追加をサポート。
