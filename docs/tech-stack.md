## 2. アーキテクチャ選定方針

1. **ゼロランタイム依存 (Zero External Dependencies)**:
   - 一般PCユーザーが利用する際に、Node.js や Docker の事前インストールを一切求めない単一バイナリ配布（`pkg`）を最優先。
2. **軽量 Vanilla フロントエンド**:
   - キャンバス描画性能とメモリ消費量を最適化するため、重厚なUIフレームワークを採用せず、Native Canvas API と Vanilla CSS による高レスポンスなUIを構築。
3. **ローカル完結ストレージ**:
   - クラウドDBや外部RDBMSを必要とせず、ファイルシステム上の `JSON` / `JSONL` のみでデータ永続化と追記同期を完結。
