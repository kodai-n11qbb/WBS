# 11.3 仕様変更履歴 (CHANGELOG.md)

[ドキュメントインデックスへ戻る](./index.md)

本ドキュメントは、WBSer の仕様策定および機能改善の履歴を記録する変更履歴です。

## [v1.18.0] - 2026-10-24

### 改善・バグ修正 (UI重なり解消 & 単独要素の常駐表示)
- **最下部コントロールの上下スタック化による重なり解消 (`public/index.html`, `public/style.css`, `docs/ui-layout.md`)**:
  - `task-input-section`（タスク追加バー）と `obsidian-inspector`（ノード詳細インスペクター）が画面下部で覆い被さっていた不具合を解消。
  - 統合フッター `.bottom-controls-dock` を新設し、上段にインスペクター、下段にタスク追加バーを上下分離して垂直スタック配置。
  - インスペクター展開時もタスク追加バーやキャンバス内の描画領域を覆い隠さず、全ボタン・入力欄の100%可読性・クリック操作性を担保。
- **単独要素（親要素・子要素なし）の常駐表示仕様の拡張 (`public/app.js`, `docs/ui-layout.md`)**:
  - 従来 `!t.dueDate`（期日未設定）に限定されていた単独要素の常駐条件を撤廃。
  - 親要素・子要素を持たない独立タスクは、完了予定日（dueDate）の有無にかかわらず他ツリー選択時でも常に画面上に常駐表示（期日未設定はZone 1待機列、期日設定済みは該当日付列）されるようロジックを更新。
- **インスペクター閉じる時の即時全体復帰 (`public/app.js`)**:
  - インスペクターの閉じるボタン（✕）押下時に `renderCurrentView()` を呼び出し、即座に全体グラフビューへ復帰するよう改善。

## [v1.17.0] - 2026-10-23

### 改善・仕様更新 (空データ時の直近架空予定自動初期化ブートストラップ)
- **空データ時の直近架空予定（サンプルデータ）自動生成仕様の導入 (`src/ui/server.ts`, `docs/database-schema.md`)**:
  - `events.jsonl` 内にタスクイベントがなく、かつ `state.json` にタスクが存在しない初回起動時、本日基準の直近架空予定（12件の階層タスク群）を自動生成して永続化するブートストラップ処理を導入。
  - 通常起動（単一バイナリ）および `npm run dev` の双方でフラグ指定不要で一貫して動作するように仕様を統一。
  - 完全に空のプロジェクトで開始したいユースケース向けに、`CREATE_DEMO_TASKS=false` による自動生成抑止オプションを提供。
- **ブートストラップ挙動の回帰テスト追加 (`tests/bootstrap_demo.test.ts`)**:
  - 空データ時の自動生成、タスクステータス集約、スナップショット整合性を検証する単体テストを追加。

## [v1.16.0] - 2026-10-18

### 改善・仕様更新 (直線エッジ統一・カーソル近傍z軸最前面化・実務デモデータセット)
- **親子接続線の直線（Straight Line）統一 (Straight Edge Connection & Directional Arrows)**:
  - タイムラインモードでの湾曲（Bézier）接続を廃止し、幾何学的整合性と依存方向の視認性に優れた直線接続（`lineTo`）に統一。親ノードから子ノードへの三角矢印マーカーを進行方向（60%位置）に端正に配置。
  - クロスゾーン接続線（期日未設定/過去/未来ゾーンとタイムライン列間の接続）も直線破線で統一。
- **カーソル接近ノード＆ラベルの動的最前面表示 (Dynamic Z-Ordering on Cursor Proximity)**:
  - 同一完了予定日や近接する相対ネストの兄弟タスク群において、マウスカーソルが接近した（ホバー中または最接近）ノードを描画ループの最後に回し、最前面レイヤー（z軸トップ）として描画。
  - 背景プレートとラベルテキストが奥のノードに隠れることなく、常に手前にくっきりと浮かび上がり高い可読性を担保。
- **現実味のある実務デモデータセット仕様策定 (`data/state.json`)**:
  - 現在日（2026年10月18日前後）を起点とした「Webプロダクト新機能リリース」実務シナリオ（30件規模・複数階層・複数親依存・未設定/過去/現在/未来の全ゾーン展開）の仕様を策定。
- **テスト戦略仕様策定 (`docs/test-strategy.md`)**:
  - Vitest 単体テスト（32件）方針に加え、Playwright による Canvas 描画はみ出し・文字衝突自動検知のテスト仕様（メトリクス・判定基準）を策定。
  - テスト生成物（スクリーンショット画像等）の出力先を `tests/display_audit/` へ統一し、アプリデータ領域（`data/`）と厳格分離した上で `.gitignore` への追加方針を明記。
- **全体グラフの過密・右端スタック解消仕様 (Overall Graph Anti-Clutter Optimization)**:
  - 初期ネスト表示のデフォルトを「2階層」に設定し、初回表示時の右端壁押し潰れや過密を完全解消。
  - 親ノードの子タスク数バッジクリックによるブランチ個別展開／折りたたみ（トグル）仕様を追加。
  - 通常グラフモードでのキャンバス左右水平ドラッグ（Pan）および画面右端クランプの撤廃仕様を策定。

## [v1.15.0] - 2026-10-18

### 改善・機能追加 (ゾーン別ラベル配置最適化・親子血統可視化)
- **ゾーン別・表示範囲別のラベル配置最適化 (Zone-Specific Label Alignment)**:
  - 未来ゾーン（Zone 4: 右端）のノードラベルをノード円の「左側」（`textAlign: right`）に配置し、画面右枠外へのはみ出しや文字詰まりを防止。
  - 過去ゾーン（Zone 2）および期日未設定ゾーン（Zone 1: 左端）のラベルをノード円の「右側」（`textAlign: left`）に配置。
  - 表示日付範囲内（メインタイムライン列上）のノードラベルをノード円の「下側」（`textAlign: center`）に配置。カレンダーの日付目盛りと調和し、縦積み時は `minDistY: 66px` および階層オフセット `68px` により上下の重なりを完全排除。
- **エッジの親→子への方向性明示 (Directional Edge Arrows)**:
  - タイムラインモード（Bézier曲線）および通常グラフモード（直線）の接続線において、親ノード（上位）から子ノード（下位）へ向かう向きを示す端正な三角矢印マーカーを描画。
- **ホバー・選択時の血統ハイライト (Lineage Glow)**:
  - ノードホバー時および選択時、対象ノードの「直親」および「直子」を結ぶ接続線（エッジ）を太く発光（Glow: `#f59e0b`）させ、非関連のエッジを一時的に減光（`alpha: 0.2`）して親子系統を即座に特定可能に。
  - キャンバス上でノードにカーソルを重ねた際、ポインターカーソルへ滑らかに切り替え。
- **ドックインスペクター内の階層パンくずナビゲーション (Inspector Breadcrumbs)**:
  - 最下部ドックインスペクター内に `階層: [ルート] > [親タスク名] > [現在タスク名]` のパンくずリストを常設。親タスクをクリックすることでワンタップで親タスクへフォーカスを移動可能に。

## [v1.14.0] - 2026-10-17

### 改善・アーキテクチャ刷新 (100vh全画面レイアウト・統合ツールバー・被り根絶)
- **100vh 全画面最適化レイアウト (Full 100vh Immersive Canvas)**:
  - `body { height: 100vh; overflow: hidden; }` を適用し、不要なページスクロールを完全根絶。画面縦いっぱいに広がる没入型グラフキャンバスを実現。
- **App-Header の撤廃とツールバー統合 (Unified 42px Headerless Toolbar)**:
  - 画面上部の肥大化したヘッダー（`.app-header`）を廃止し、ロゴ・タイトル（`WBSer`）、Node接続状況バッジ、元に戻す（`↺ 戻す`）、ダーク/ライトテーマ切替ボタンをすべてグラフ上部の `.graph-top-toolbar`（高さ42px）へスマートに集約。
- **インスペクターのドック配置 (Docked Inspector above Input Section)**:
  - 従来キャンバス中央に浮動表示（フローティング）してノードを隠していたノード詳細インスペクター（`#obsidian-inspector`）を、画面最下部タスク入力バー（`#task-input-section`）の直上へ横幅いっぱいのドック型パネルとして常設再配置。ノードや線との被りを完全に解消。
- **ガントチャートビューの廃止 (Retire Gantt View)**:
  - 冗長化していたガントチャート（`#gantt-view`）およびビュー切替スイッチを撤廃。Obsidian Graph & タイムラインキャンバス単一の高速・洗練された体験に特化。
- **親要素移動ボタンの廃止 (Remove Parent Nav)**:
  - `#graph-parent-nav`（← 親要素へ移動）をUIおよびロジックから完全撤廃。キャンバス背景クリックでの選択解除やパン・ズームによる直感操作へ統一。
- **タイムライン過去日付の動的列配置 (Dynamic Timeline Past Date Placement)**:
  - 完了予定日が過去のタスクについて、タイムライン表示範囲内（左ドラッグ・パンで可視化された過去日付列）に存在するものはその日付列へ直接配置。タイムライン左端を越えてスクロールアウトした古い日付のみを中立的な「◀ 過去」ゾーンへ集約。
- **要素選択時の非関連ノード完全非表示 (Complete Isolation of Subtree Nodes)**:
  - タスク選択時、選択タスクとその子孫以外の非関連ノードの半透明（ゴースト）表示を全廃。選択サブツリーのみをクリーンに描画し、視覚ノイズをゼロ化。
- **タイムラインノードラベルの右側配置による被りゼロ化 (Zero-Collision Timeline Labels)**:
  - 同一完了予定日を持つ複数のタスクが縦一列に並んだ際、ノード下部にラベルを表示すると上下で重なってしまう問題を解決。タイムラインモード時はラベルをノード円の右側へ左揃え配置（`lx = node.x + haloRadius + 8`）することで、縦積みノードとの衝突を数学的に根絶。
- **通常グラフモードでの動的兄弟間隔計算 (Dynamic Sugiyama Clearance)**:
  - Sugiyamaツリー配置において、兄弟ノードのタイトル文字長を計測し動的な水平クリアランス（`Math.max(145, (prevW + curW)/2 + 30)`）を適用。長い名前のタスク同士でも文字重なりが発生しないレイアウトを実現。
- **ウィンドウ／コンテナサイズ変更時の自動追従リサイズ (ResizeObserver Auto-Resize)**:
  - `ResizeObserver` および `window.onresize` を導入し、ブラウザのリサイズやインスペクターの開閉に伴うコンテナ伸縮にキャンバス解像度と描画スケールがリアルタイムに自動追従。クリックや再描画操作を不要化。

## [v1.13.0] - 2026-10-17

### 改善・修正 (7つのUI/UX課題の全面改修)
- **グラフ上部専用ツールバー新設による日付バー被り解消 (Dedicated Top Toolbar)**:
  - 親要素移動ボタン（`#graph-parent-nav`）およびネスト/日数/フォント制御（`#depth-filter-control`）をキャンバス内オーバーレイから独立させ、グラフ上部に `.graph-top-toolbar` として常設配置。日付目盛りバーやタスクノードへの重なりを100%排除。
- **同日タスクの厳格な同一X軸配置 ＆ 縦積み重なり防止 (Exact Same X Alignment for Same Due Dates)**:
  - タイムラインモードにおいて、同一の完了予定日を持つタスク群のX座標を完全に統一。横方向のズレをなくし整然とした日付列を形成。
  - 縦方向は階層深度および兄弟インデックスに基づき `54px` の間隔を保証し、`56px` の垂直物理反発力場により同日兄弟ノード同士のテキスト重なりを防止。
- **兄弟要素同士の文字重なり防止強化 (Sibling Text Collision Elimination)**:
  - Sugiyamaツリー配置アルゴリズムにおいて同一階層のタスク間に `135px` 以上の水平距離を強制設定。
  - 物理シミュレーションのラベル反発強度を強化（`0.75`）し、通常グラフモードでの兄弟ラベル衝突を根絶。
- **過去ヘッダーの中立表記化 (Zone 2 Header Renamed to "◀ 過去")**:
  - Zone 2 の表記を「◀ 過去 (遅延)」から「◀ 過去」へと改称し、過去のタスクを遅延と決めつけず中立なスレートカラーで美しく整理。
- **完了予定日変更時の確認ダイアログ導入 (Reschedule Confirmation Modal)**:
  - タイムライン上でのドラッグ＆ドロップ、インスペクターの日付ピッカー操作、ガントチャート上でのマーカードラッグ変更時に、「完了予定日を変更しますか？」の確認ダイアログを表示。Enterで確定、Escでキャンセル・復帰。
- **タスク削除アラート即時消失バグの根絶 (Safe In-App Deletion Modal)**:
  - フォーカス喪失や描画フレームとの競合で一瞬で閉じてしまっていたブラウザ標準 `window.confirm` を全廃し、カスタム確認モーダル（`#confirm-parent-modal`）による安全確実な削除フローへ刷新。
- **期日外要素との接続ラインの美麗化 (Graceful Bézier Cross-Zone Curves)**:
  - 「期日未設定」ゾーンおよび「過去」ゾーンからタイムライン上のタスクへ繋がる接続線を、武骨な斜め直線から、柔らかな半透明アンバーの破線 Bézier 曲線（`rgba(245, 158, 11, 0.45)`）へ刷新。

## [v1.12.0] - 2026-10-17

### 追加・改善
- **日付軸の4専用ゾーン分離表示 (4-Zone Date Axis Partitioning)**:
  - 要素選択（タイムラインモード）時の画面上部日付軸を「📅 期日未設定」「◀ 過去 (遅延)」「メインタイムライン（今日〜+N日）」「未来 ▶ (期間外)」の4つの明確な専用ゾーンに区分。
  - 期限が設定されていない要素と、表示期間外（過去の遅延タスクや遥か先の未来タスク）にある要素を整然とした縦列で分離表示。
- **タスク状態バッジの明記表示 (Explicit Status & Date Badges on Nodes)**:
  - サブツリー配下ノードのラベルに `[未設定]`, `[M/D 過去]`, `[M/D]`, `[M/D 未来]` を付与し、ひと目で分類状態が把握可能に。
- **タイムライン上ドラッグ＆ドロップによる完了予定日直感更新 (Drag-and-Drop to Reschedule)**:
  - タイムラインモード時、タスクノードを目的の日付列へドラッグ＆ドロップするだけで `dueDate`（完了予定日）を即座に更新。
  - 「📅 期日未設定」ゾーンへドロップすることで、ワンアクションで期日の未設定化（クリア）が可能。
  - ドラッグ中は対象日や未設定状態をリアルタイム表示するライブツールチップが表示され、ドロップ後はトースト通知で視覚的に案内。
- **日付軸モード時の誤結合防止 ＆ 背面ノードへのドロップ結合無効化 (Accidental Parenting Prevention)**:
  - タイムラインモード中はノード間の親子結合判定を自動無効化し、期日変更操作中の誤ったツリー組み替えを完全防止。
  - 通常モードを含め、半透明で薄く表示されている背景ノード上にドロップしても親子結合が発生しないよう保護。
- **デモデータの直近化 (Realistic Recent Demo State)**:
  - `data/state.json` および `data/events.jsonl` のデモタスクの日付を本日（2026年10月17日）周辺の実践的な日付群（過去・本日・数日後・未設定）に刷新。

- **アプリ正式名称変更**: プロジェクト名称を **WBSer** に更新。
- **端末単位 Undo (1つ戻す) 機能**:
  - 自端末（`authorNodeId`）が実行した直前のアクション（作成・編集・削除）を取り消す `UNDO_ACTION` イベント発行＆状態復元メカニズムを実装。
- **進行中 (IN_PROGRESS) ステータス時の完了予定日必須化**:
  - ステータスを `IN_PROGRESS` に設定する際、完了予定日（`dueDate`）の入力をドメインバリデーション ＆ UI ダイアログにて強制化。
- **Graph View 視覚的親表示・最上部焦点移動 ＆ 左上親ナビゲーションUI**:
  - ノードクリック時、親要素との接続（上方向リンク発光）を視覚的に示しつつ、クリックノードを最上部へ自動焦点移動し配下全子要素を展開。
  - 左上に `position: absolute` の親ナビゲーションパネル（`← 親要素へ移動: [親名]`）を設置。
- **隠しデータ保存ディレクトリ互換性 (`./.wbser_data`)**:
  - 既存の `./.wbser_data` フォルダに対する自動フォールバック検出互換性を保持。
- **ガントチャート親完了予定日超過赤表示 ＆ ヘッダー幅一致修正**:
  - 子タスクの完了予定日が親の完了予定日を超過している場合、差分期間を赤くハイライト描画し「`+N日遅延`」の警告バッジを表示。
  - `gantt-ticks-header` のグリッド幅を `gantt-bar-cell` と完全に同等化。
- **3子要素以上削除時の理由ログ必須化**:
  - 3つ以上の子要素を持つ親タスク削除時、10文字以上の理由入力ダイアログを表示し、`TASK_DELETED` イベントの `reason` プロパティへ記録。
