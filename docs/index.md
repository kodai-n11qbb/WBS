# WBSer プロジェクト仕様ドキュメント インデックス

本ドキュメント群は、分散・ローカルファーストタスク管理システム **「WBSer」** の概念、システムアーキテクチャ、データモデル、同期仕様、および拡張設計を定義する技術仕様書です。
開発方針については [`../DEV_POLICY_v1.0518.md`](../DEV_POLICY_v1.0518.md) を厳守します。

---

## ドキュメント構成

1. [01. 概念とユースケース](./01_concept.md)
   - 本システムのコアコンセプト、Obsidian型ノードグラフ前面配置（焦点移動・親ナビゲーションUI・サブツリー強調・文字重なり防止・キャンバス空白クリック解除）、GanttProjectスタイルガントチャート（親完了予定日超過赤表示・ヘッダー幅完全一致・副タイトル削除・完了予定日マーカードラッグ）、動作モード（P2P / CLIENT / HOST）、解決する課題
2. [02. システムアーキテクチャ抽象](./02_architecture.md)
   - Hexagonal / Clean Architecture に基づくレイヤー構造とコンポーネントポート定義、DI（依存性注入）方針、端末単位Undoポート、削除理由ログ検証ポート、隠しデータ保存ディレクトリ (`./.wbser_data`)、スタンドアロン単一バイナリ構造
3. [03. データモデルと同期仕様](./03_data_sync.md)
   - ミニマルタスクエンティティ、進行中完了予定日必須仕様、3子要素以上削除理由ログ仕様、`./.wbser_data/state.json` スナップショット仕様、`config.json` スキーマ、対話型セットアップCLI、イベントログ同期 (`events.jsonl`) メカニズム
4. [04. 拡張性およびプラグイン設計](./04_extension_spec.md)
   - WBSer単一バイナリ配布パッケージング (`wbser-win.exe` / `wbser-macos-arm64`)、隠しデータディレクトリ保護 (`./.wbser_data`)、対話型セットアップ、通信・ストレージアダプター拡張ポイント、相対パス保守ルール

## 仕様の変更履歴

- **v1.7.0 (2026-09-23)**:
  - **アプリ正式名称変更**: プロジェクト名称を **WBSer** に更新。
  - **端末単位 Undo (1つ戻す) 機能**: 自端末 (`authorNodeId`) が実行した直前のアクション（作成・編集・削除）を取り消す `UNDO_ACTION` イベント発行＆状態復元メカニズムを実装。
  - **進行中 (IN_PROGRESS) ステータス時の完了予定日必須化**: ステータスを `IN_PROGRESS` に設定する際、完了予定日 (`dueDate`) の入力をドメインバリデーション ＆ UI ダイアログにて強制化。
  - **Graph View 視覚的親表示・最上部焦点移動 ＆ 左上親ナビゲーションUI**: ノードクリック時、親要素との接続（上方向リンク発光）を視覚的に示しつつ、クリックノードを最上部へ自動焦点移動し配下全子要素を展開。左上に `position: absolute` の親ナビゲーションパネル (`← 親要素へ移動: [親名]`) を設置。
  - **隠しデータ保存ディレクトリ (`./.wbser_data`)**: 共有データの誤削除・破損を防ぐため、デフォルト保存場所を隠しフォルダ `./.wbser_data` に変更（既存 `./data` との自動フォールバック互換性保持）。
  - **ガントチャート親完了予定日超過赤表示 ＆ ヘッダー幅一致修正**: 子タスクの完了予定日が親の完了予定日を超過している場合、差分期間を赤くハイライト描画し「`+N日遅延`」の警告バッジを表示。`gantt-ticks-header` のグリッド幅を `gantt-bar-cell` と完全に同等化。
  - **3子要素以上削除時の理由ログ必須化**: 3つ以上の子要素を持つ親タスク削除時、10文字以上の理由入力ダイアログを表示し、`TASK_DELETED` イベントの `reason` プロパティへ記録。
- **v1.6.0 (2026-09-23)**:
  - グラフビューに **Sugiyama風レイヤード・ツリー自動配置アルゴリズム (Sugiyama Untangled Tree Layout)** を導入。
  - **ネスト数による縦方向自動スケール (Dynamic Y Ratio Scaling)**: 可視タスクの最大ネスト数に応じた縦幅自動均等分割。
  - **焦点要素の最上部昇降アニメーション (Focal Elevation)**: 臨界減衰物理の適用。
  - **文字サイズ選択機能 (Text Size Selector)**: コントローラーから文字サイズ切り替え。
- **v1.5.0 (2026-09-23)**:
  - グラフビュー初期描画時のノード絡まり防止アルゴリズム（Radial Sector Physics Layout）を導入。
  - 配下の子孫タスク群およびリンクの強調ハイライト。
  - ノードラベル文字の重なり防護プレート描画。
  - キャンバス空白部クリックによる選択フォーカス解除。
- **v1.4.0 (2026-09-23)**:
  - グラフビューのネスト表示デフォルトを「すべて」に変更。
  - ガントチャートの完了予定日マーカー (`🚩`) 直接ドラッグ＆ドロップ操作機能。
- **v1.3.0 (2026-09-22)**:
  - 画面仕様を グラフ ＆ ガント の 2ビュー構成に特化。
  - Enter / Esc キーボードショートカット操作対応。
  - 表記を「完了予定日」に統一。
- **v1.2.0 (2026-09-22)**:
  - Linear / Raycast スタイルテキストデザインシステム導入。
  - 不変イベントログからの不完全作業期間プロット型ガントチャートを導入。
- **v1.1.0 (2026-09-22)**:
  - 3つの動作モード（P2P / CLIENT / HOST）と `config.json` スキーマ仕様を追加。
- **v1.0.0 (2026-09-20)**:
  - ローカルファースト P2P タスク同期ツールの基本仕様を策定。
