## 1. グラフビュー・インタラクション

### (1) ノードシングルクリック (Focus, Relative Nest & Date-Axis Timeline Mode)
- **挙動**:
  - 対象ノードを選択し、詳細インスペクターパネルを展開。
  - 親タスクが存在する場合、上方向への接続線（発光・点線）を視覚的に強調。
  - 左上に `.graph-parent-nav`（`← 親要素へ移動: [親タスク名]`）を表示。
  - 選択ツリー以外の背景ノードは透過度を下げ（Dim表示）、選択サブツリーの視認性を最大化。
  - **【新仕様】選択サブツリーの日付軸（タイムライン）マッピング ＆ ゾーン分離**:
    - クリックされた要素およびその配下の全子要素群が、今日（Today）を起点とする**日付の軸（Time Axis）**に乗っかる配置へスムーズに移動。
    - キャンバス上部に「📅 期日未設定」「◀ 過去」「今日〜+N日タイムライン」「未来 ▶」のゾーンを描画。
    - **未設定タスク**: 完了予定日のないタスクは左端「📅 期日未設定」枠へ配置。
    - **過去タスク**: 完了予定日が今日より前のタスクは「◀ 過去」枠へ配置し、ラベルに「`[10/15 過去]`」と表示。
    - **未来タスク**: 選択日数（例: 14日）を超えるタスクは右端「未来 ▶」枠へ配置し、ラベルに「`[11/15 未来]`」と表示。
    - **タイムライン内タスク**: 各日付列へ吸着配置され、ラベルに「`[10/20]`」と表示。
    - **キャンバス横スクロール/ドラッグ（Pan）**: キャンバスをドラッグ操作することで、過去や未来のタスクへも自在に横スクロールして見渡すことが可能。
  - **【新仕様】ドラッグ＆ドロップによる完了予定日直感変更**:
    - 日付軸モード時、ノードをドラッグして日付列上にドロップすると、その日付が自動的にタスクの完了予定日（`dueDate`）として更新される。
    - 左端の「📅 期日未設定」枠内にドロップすると、期日未設定（`null`）にリセットされる。
    - ドラッグ中は対象日付を示すツールチップ（`📅 10月20日に設定` や `📅 期日未設定にする`）がリアルタイム表示される。
    - **誤結合防止**: 日付軸モード時、背景の薄い（非選択）ノードへのドロップによる親子結合は無効化される。
  - **【新仕様】表示日数（タイムライン範囲）切り替えボタン**:
    - 画面端コントローラーに表示日数切り替えボタン（`[ 7日 ] [ 14日 ] [ 30日 ] [ 60日 ]`）を配置。
    - ボタン押下により、日付軸のレンジ・スケールが即時変更され、初期スクロール位置が「今日」を基準に再調整される。
  - **【新仕様】選択要素起点での相対ネスト表示切り替え**:
    - 要素未選択時は「全体（ルート起点）」で階層深度（1階層/2階層/3階層/すべて）をフィルタ。
    - **要素選択時は「クリックされた要素を起点」とした相対階層数**で配下の表示範囲をフィルタ（例: 1階層＝選択要素自身＋直下の子要素、2階層＝孫まで、すべて＝全子孫）。

### (2) ノードダブルクリック (Subtree Focus Mode)
- **挙動**:
  - 対象ノードが画面最上部のルート頂点となるようフォーカス配置。
  - 対象ノードと配下の子孫要素群のみが存在するかのように他要素を非表示化（Subtree Isolation）。
  - 日付軸タイムライン表示を維持したまま、他ツリーを完全に隠して特定機能群のスケジュールと構造に完全集中。

### (3) キャンバス空白部クリック (Clear Selection)
- **挙動**:
  - ノード以外のキャンバス背景をクリックすると、選択状態（フォーカス）が解除され、インスペクターパネルが閉じる。
  - 日付軸タイムライン表示が解除され、通常の物理バネ ＆ Sugiyama階層グラフ配置へスムーズに復帰。
  - ネスト表示切替の基準も「全体ツリー（ルート起点）」へ自動復帰。

### (4) ノードのドラッグ ＆ 親子付け替え / ルート化
- **通常モード（未選択時）でのノード同士のドロップ**:
  - 通常グラフモード時、ノードAをノードBの上にドラッグして離すと、確認ダイアログが表示され、ノードAの親がノードBに変更される。
- **日付軸モード時**:
  - ドラッグ＆ドロップは日付変更・期日未設定化として動作し、背景ノードとの結合は無効化。
  - 日付列または期日未設定ゾーンにドロップした際、「タスク『...』の完了予定日を◯◯に変更しますか？」の確認ダイアログが表示され、Enterで確定、Escまたはキャンセルで操作を取り消し。
  - インスペクター内の完了予定日入力ピッカーやガントチャート上のマーカードラッグ変更時にも同確認ダイアログが適用され、キャンセル時は変更前の期日へ自動復帰。
- **最上部ドロップゾーンへのドラッグ (In-Canvas Root Elevation)**:
  - ノードをキャンバス最上部（`Y <= 60px`）へドラッグすると、青いガイドライン（`#root-dropzone`）が点灯。
  - その位置でドロップすると親タスクが解除され、ルートタスク（`parentId: null`）へ昇格。

## 2. ガントチャート・インタラクション

### (1) 完了予定日マーカー (🚩) のドラッグ＆ドロップ
- **挙動**:
  - ガントチャート上の完了予定日マーカー（🚩）をマウスで掴んで左右にスライド。
  - スライダーの位置に応じた日付がリアルタイムにツールチップ表示。
  - マウスリリース時に期日変更確認モーダルが表示され、Enterで確定後に `UPDATE_DUE_DATE` を送信・全端末同期。キャンセル時は元の位置へ復帰。

### (2) 自動遅延警告判定 (Overdue Red Highlight)
- 子タスクの `dueDate` が親タスクの `dueDate` より後ろ（未来）になった場合、自動的に赤色ハイライトグラデーションおよび「`+N日遅延`」警告バッジが描画される。

## 3. モーダル・ダイアログ操作

### (1) タスク削除のカスタム確認モーダル
- インスペクター内の「削除」ボタン押下時、ブラウザ標準の `window.confirm`（フォーカス喪失やレンダリングループにより一瞬で閉じる不具合を根絶）に代わり、アプリ内カスタムモーダル（`#confirm-parent-modal`）を表示。
- Enterキーで削除実行、Escキーまたは「キャンセル」で安全に中断。

### (2) 完了予定日変更の確認モーダル
- タイムライン上でのドラッグ＆ドロップ、インスペクターの日付ピッカー変更、ガントチャート上でのマーカードラッグ操作時に起動。
- 誤操作によるスケジュール破壊を未然に防止。Enterで確定、Escで変更前の日付を維持。

### (3) 進行中 (IN_PROGRESS) ステータス変更時の期限設定モーダル
- インスペクターでステータスを「進行中」にした際、`dueDate` が未設定なら自動ポップアップ。
- 日付を入力して Enter または「設定して進行中にする」を押下するまで、ステータス変更は保留。Escキーでキャンセル。

### (4) 3子要素以上削除時の理由入力モーダル
- 3つ以上の子要素を持つ親タスクを削除しようとすると自動ポップアップ。
- テキストエリアに 10文字以上 の理由を入力するまで「削除実行」ボタンは無効化（disabled）。

## 4. キーボードショートカット

| キー | コンテキスト | 動作 |
| :--- | :--- | :--- |
| **`Enter`** | タスク追加プロンプト | タスクを即座に作成 |
| **`Enter`** | 各種モーダルダイアログ | 決定・確定アクションを実行 |
| **`Esc`** | 各種モーダルダイアログ | モーダルをキャンセルして閉じる |
| **`Esc`** | グラフキャンバス | インスペクターパネルを閉じ、フォーカス解除 |
