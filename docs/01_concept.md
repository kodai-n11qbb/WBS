## 1. 全体概要
本システムは、中央サーバーを必要としない対等な **分散モード (P2P)**、指定ホストに接続する **クライアントモード (CLIENT)**、および自端末で接続を受け付ける **ホストモード (HOST)** の3つの柔軟な運用形態に対応した、プロジェクト進行管理ツールです。

**「Local-First（ローカルファースト）」** 本ツールでは、全体の構造化と「全体像が見えること」を最優先とし、**Obsidian型ノードグラフ表示を主軸（前面）**に配置した全画面キャンバスと、**GanttProjectスタイルの日付管理ガントチャート**の **2つの主要ビュー構成** とします（従来のツリー・カンバンビューは排し、グラフビューとガントチャートに特化・単純化）。絵文字や過剰なグラデーション、Blob背景アニメーションを排し、エンジニアリング重視の静かで高コントラストなテキスト主体デザインシステム（Dark / Light モード対応）を提供します。

```
+-----------------------------------------------------------------------------------------+
| [Share-Log] [Node: dev-1]             [ グラフ | ガント ]             [ ダーク/ライト ] |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|      (親ノード) ← 画面上部へ配置 (Y軸重力・絡まり防止放射状初期配置)                    |
|          ◯                                                                              |
|         / \                                                                             |
|        ◯   ◯ (ノードクリック → 配下サブツリー強調 ＆ 文字重なり防止)                   |
|             │   ┌────────────────────────────────────────────────────────┐              |
|             └──>│ [タイトル編集] [完了予定日:YYYY-MM-DD] [TODO/進行中/完了] [ルート化] │ |
|                 └────────────────────────────────────────────────────────┘              |
|                                                            [画面端 ネスト表示切替]      |
|                                                            | 1階層 | 2階層 | [すべて] |  |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
|                      画面下部固定 タスク追加プロンプトバー                               |
|  [ ルートタスク ▾ ]  タスク名を入力してEnter...                             [ 作成 ]    |
+-----------------------------------------------------------------------------------------+
```

### (1) 前面化された Obsidian型 物理グラフィカルキャンバス (Obsidian Graph View)
- **前面メイン画面化**: アプリの標準画面としてグラフキャンバスを前面に配置。
- **実用重視のテキスト・モノトーンデザイン**: 絵文字やド派手なエフェクトを廃し、Linear / Raycast 風のクリーンなグリッドとソリッド境界線を採用。
- **ネスト表示深度のデフォルト「すべて」**: 初期起動・表示時に全階層のタスクノードを全展開して俯瞰。
- **Sugiyama風レイヤード・ツリー自動配置 ＆ 交差完全防止 (Sugiyama Untangled Tree Layout)**:
  - 末端タスク数（Leaf Count）の再帰採寸によりサブツリー同士のX座標領域を非交差計算し、描画時および物理収束時の線の絡まり・交差を幾何学的に解消。
- **ネスト数による縦方向自動スケール (Dynamic Y Ratio Scaling)**:
  - 可視タスクの最大ネスト数（1〜N階層）に応じてキャンバスの縦領域を自動均等分割。浅い階層でも間延びせず、深い階層でも全てのノードが画面内に美しく収まるダイナミック配置。
- **焦点要素の最上部昇降 ＆ 臨界減衰物理 (Focal Elevation & Critical Damping)**:
  - **ノードシングルクリック**: 対象ノードおよび配下ツリー全体が画面最上部へスッと浮上し、配下タスク全体をスクロールフリーで可視化。揺れやバウンドを抑えた臨界減衰（Critical Damping）を適用。無関係ノードは半透明化（ディミング）。
- **Retina/High-DPI ディスプレイ高解像度描画 (Crisp High-DPI Rendering)**:
  - `window.devicePixelRatio` を自動検出して Canvas の物理ピクセル解像度と CSS 仮想解像度を適合・スケーリング (`ctx.scale(dpr, dpr)`)。Mac や 4K Retina ディスプレイ環境でノードの円、文字、および線描画がボケずにクッキリ美しく表示されます。
- **文字サイズ選択 ＆ キャンバス空白部クリックによるフォーカス解除**:
  - 画面端のコントローラーからネスト表示切替に加え、文字サイズ（小 / 中 / 大）を即座に選択可能。
  - ノード以外のキャンバス空白部分をクリックした際、選択状態（フォーカス）を解除し「何も選択していない初期状態」に即座に復帰。
- **ノードドラッグによる親指定とキーボード決定**:
  - ノードを別のノードへドラッグすると確認モーダルが表示され、**Enter キーで即時確定**、**Esc キーで即時キャンセル**が動作。
- **キャンバス内上部ルート化ドロップゾーン (In-Canvas Root Zone)**:
  - キャンバス内でノードをドラッグ中、キャンバス内最上部 (`Y <= 60px`) に直接 `[ ここにドロップして親を解除 (ルートタスク化) ]` エリアを描画。ノードを上部エリアで離すことで範囲外に出ることなく確実にルート化を実行。

### (2) 子要素のルート要素化メカニズム (Subtask-to-Root Elevation)
GraphビューおよびGanttビューにおいて、直感的な操作感で子タスクをルート階層 (`parentId: null`) へ移動可能：
1. **ノード クイック操作ボタン**: インスペクターの `[ ルート化 ]` ボタンを押す。
2. **キャンバス内上部ドロップエリア**: グラフキャンバス最上部へドロップするだけでルート化。

### (3) 「開きたくなる・見たくなる」GanttProject進化系ガントチャート (Linear/Raycast Style Modern Gantt View)
- **開発目的**: 従来の GanttProject や Excel ガントチャートの最大の欠点である「無骨でダサく、開いて見ようという気にならない」というUX課題を根本解決。Linear / Raycast スタイルの洗練されたダーク/ライトテーマ、半透明ガラスモルフィズム、スムーズな進行度グラデーションバーにより、毎日開きたくなる美しい視覚体験を提供。
- **左右2分割 クリーンレイアウト（日付単位管理 ＆ 最長完了予定日の自動収容）**:
  - ヘッダー下の不要な副タイトルを廃し、無駄のない洗練されたミニマルヘッダーを採用。
  - **左側スプレッドシート型ツリーテーブル**: 階層構造タスク名（洗練されたガイド線 `│ ├─`）、ステータスバッジ（ワンタップ切り替え）、完了予定日 (`YYYY/MM/DD`)、所要日数 (`◯日`)。
  - **右側タイムラインエリア**: 時間軸目盛り（日付単位・5分割表示）、実稼働期間発光バー (`IN_PROGRESS` Window)、完了予定日ネオンマーカー (`gantt-due-marker` 🚩)。
- **完了予定日マーカー (`🚩`) の直感的ドラッグ＆ドロップ編集**:
  - ガントチャート上の完了予定日マーカー (`🚩`) をマウスで掴んで左右にスライド（ドラッグ）することで、**直感的に完了予定日 (`dueDate`) を変更**。ドラッグ中はリアルタイムで変更後の日付 (`YYYY/MM/DD`) ツールチップを表示し、ドロップ時に即座に自動保存・同期。
- **最長完了予定日の全領域自動スケール (Auto-Fit Range)**:
  - プロジェクト内の全タスクの中で**一番遠い完了予定日 (`dueDate`) を自動判定**し、タイムライン右端内にマーカーやバーが完全に収まるようスケールを自動調整。
- **直感的な進行度切替**:
  - ガントテーブルのステータスバッジまたはタイムラインバーをクリックすることで、即座にステータス (`TODO` ⇄ `進行中` ⇄ `完了`) を切替。

### (4) 画面端のネスト表示深度調整 (Screen Edge Nesting Depth Control)
- 画面端に配置されたシンプルで視認性の高い深度切り替えコントローラー（1階層 / 2階層 / 3階層 / すべて）。デフォルトは「すべて」。

### (5) クリーンなヘッダー ＆ テーマ切替 (Clean Header & Theme Switcher)
- 最小限のタイトル、ノード接続状態、2つのビュー切替 (`[ グラフ | ガント ]`)、およびダーク / ライトテーマ切替ボタン `[ ダーク / ライト ]` を配置。

## 3. ディレクトリ直下の最新状態スナップショット運用 (`data/state.json`) ＆ 動作モード
- **最新状態スナップショット (`data/state.json`)**:
  - タスクの追加・変更・削除のたびに、指定ディレクトリ内の `data/state.json` に最新の全タスク状態（Materialized Snapshot）がリアルタイム自動保存されます。
- **動作モードとアドレス設定**:
  - **`P2P` (分散モード)**: 共有データのアドレス（`data/state.json` のパス）を指定して分散動作。
  - **`CLIENT` (クライアントモード)**: 接続先ホストの端末アドレス（IP/ポート）を指定して接続。
  - **`HOST` (ホストモード)**: 自身を親機として起動しクライアント接続を受付。

## 4. 解決する課題
- **全体像と構造化の可視性**: 全体が俯瞰できる前面グラフビュー（デフォルト全階層表示・初期配置絡まり防止）と、日付単位で管理可能な時系列ガントチャートにより、多角的にタスクの繋がり・完了予定日・進捗状況を把握。
- **直感的なノード編集・ガントマーカードラッグ操作**: キャンバス上のノード編集やガント予定日マーカー (`🚩`) の掴んで離す直感ドラッグ操作、サブツリー強調・文字重なり防止機能、Enter/Esc確定ショートカットからタイトル編集・完了予定日設定・ステータス変更・ルート化を迅速に完結。
- **洗練された視覚デザイン**: 静かで集中できる Linear/Raycast スタイルの高コントラスト UI とダーク/ライトモード対応。
- **柔軟な運用形態**: 分散P2P・クライアント接続・ホスト運用の3モードを自由に切り替え。

---

## 5. 拡張性を担保する原則
- **ローカル優先・非同期伝播**: 変更は常にローカルの `data/state.json` および `.jsonl` ファイルへ即座に記録し、P2Pネットワークへは非同期で波及させる。
- **UI 非依存 Core**: Obsidianグラフキャンバスおよびガントチャートのいずれにも移植できるモジュール構造とする。
