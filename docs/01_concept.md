# 01. 概念とユースケース

[インデックスへ戻る](./index.md)

---

## 1. 全体概要
本システムは、中央サーバーを必要とせず、同一ローカルエリアネットワーク (LAN) 内に存在する端末同士が直接通信（P2P）することで、プロジェクトの進捗・タスク状態・アクティビティを共有・管理するためのツールです。

**「Local-First（ローカルファースト）」** 設計思想、**「Obsidian型ノードグラフ表示 (Obsidian-like Graph View)」**、および **「Gitライクな追跡ログ (JSONL Append-Only Log)」** を採用しており、美しい視覚的ノードネットワークと爆速操作を実現します。

---

## 2. ビジュアル表現モード ＆ 下部固定 ChatGPT風プロンプトバー

本ツールでは、複雑な項目入力を廃止したミニマル設計を基礎とし、画面下部に固定される ChatGPT 風の直感的なプロンプトバーと用途に合わせた **3つのビジュアル表現モード** を提供します。

```
+-----------------------------------------------------------------------------------------+
|                      画面下部固定 ChatGPT風タスク追加プロンプトバー                       |
|  [📁 ルートタスク ▾]   タスク名を入力してEnter... (カード間ドロップで親子化可能)        ( ↑ )   |
+-----------------------------------------------------------------------------------------+
                                         |
     +-----------------------------------+-----------------------------------+
     |                                   |                                   |
     v                                   v                                   v
【1. 樹状ツリービュー (Tree View)】  【2. Obsidian型グラフビュー (Graph)】 【3. カンバンビュー (Kanban)】
・区分けなしの高度な視認性ツリー    ・暗闇に浮かぶノード物理ネットワーク・親タスクを最上部に優先配置
・コネクタ線付きの洗練された階層   ・バネ物理（ドラッグ時に他ノードが連動）・末端タスクをステータスカラムへ
・親進捗率(`66%`) + 🔒自動算出表示  ・ルートノードの重ね合わせで親子化確認 ・進捗度付き親カードのサマリー視認
・全階層ステータスバッジ直接操作   ・ノードクリックで該当カードフォーカス
```

### (1) 画面下部固定 ChatGPT風プロンプトバー (Bottom Fixed Floating Prompt Bar)
- **画面下部への固定配置**: 画面最下部に `position: fixed` で常時浮遊表示される ChatGPT 風の丸みのある入力バー (`border-radius: 24px`, ガラスモフィズム, フォーカス発光)。
- **インライン親タスク指定**: バー左端に `📁 ルートタスク ▾` ピルタグを内包し、ワンタップで親子関係を選択してタスク作成。

### (2) 樹状ツリービュー (Pure Tree View - 改良視認性)
- **高度なツリー視認性**: カラム分割を廃止し、**明確な接続線（Connector lines）とインデント** を用いたレスポンシブな樹状ツリー。画面サイズを問わず直感的に階層構造を把握可能。
- **親タスクのステータス自動算出とロック**: 親タスクは `🔒 自動算出 (完了度 66.7%)` ＋ プログレスバーを表示。末端タスクには `[TODO]` `[PROGRESS]` `[DONE]` バッジが表示されダイレクト操作が可能。

### (3) Obsidian型物理グラフィカルキャンバス (Obsidian Spring Physics Canvas)
- **バネ物理 (Spring Elasticity) による滑らかな連動**: ノードをドラッグした際、接続されている他のノードがバネのように引きずられて連動・追従する物理シミュレーション。
- **ルートノードのドロップ親子化（確認アラート付き）**: 親を持たないルートノードを他のノードの上に重ねてドラッグ＆ドロップすると、「タスク『A』を『B』の子タスクにしますか？」の確認ダイアログが表示され、承認で即座に親子関係を設定。
- **ノードクリックフォーカス同期**: ノードをクリックすると、直ちにツリー/カンバン表示の該当タスクカードへフォーカス・スクロール移動。

### (4) カンバンビュー (Kanban View - 親タスク優先配置)
- TODO / IN_PROGRESS / DONE の 3カラム分割による進捗一括管理。
- **親タスクの上部優先ソート**: 子タスクを持つ「親タスク」は各カラムの最上部に優先配置され、全体の進捗サマリーとしてカードを視認可能。

---

## 3. 解決する課題
- **区分けカラムによるツリーの分断を防止**: カラム枠を取り払い、高度な視認性を持つ樹状ツリーとして一覧。
- **プロジェクト全景の没入的物理操作**: バネ物理連動やドラッグ重ね合わせによる直感的な親子設定。
- **ポータブルなデスクトップバイナリ配布**: Node.js/Python 等が入っていない環境でも、単一バイナリ (`.exe` / `.app`) をダブルクリックするだけで即時起動。

---

## 4. 拡張性を担保する原則
- **ローカル優先・非同期伝播**: 変更は常にローカルの `.jsonl` ファイルへ即座に記録し、P2Pネットワークへは非同期で波及させる。
- **トランスポート透過性**: P2P 通信が UDP/TCP/WebSockets/WebRTC のいずれであっても、進行管理のドメインロジックに影響を与えない設計とする。
- **UI 非依存**: CLI、純粋ツリービュー、Obsidianグラフキャンバス、カンバンビュー等のいずれにも移植できる構造とする。
