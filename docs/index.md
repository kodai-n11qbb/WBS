## ドキュメントの保守方針
- すべての内部リンク・参照パスは**相対パス**で記述すること。
- モジュール間の依存はインターフェース定義（抽象）にとどめ、特定のトランスポート層（TCP/UDP/WebRTC等）やストレージ（SQLite/JSON等）に直接依存させないこと。
