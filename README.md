# WBSer - Local-First P2P Project Tracker

**WBSer** は、ローカルファースト思考で設計された、分散 P2P / ホスト / クライアント対応のプロジェクト進行管理システムです。

前面に配置された **Obsidian型物理ノードグラフ** と、**GanttProjectスタイル ガントチャート** の2主要ビューを備え、プロジェクトの全体構造と進行状況を直感的に把握できます。

---

## 🚀 クイックスタート

### 1. 対話型セットアップ ＆ 設定 (`config.json`)
```bash
npm run setup
```
画面の案内に従って動作モード（`P2P` / `CLIENT` / `HOST`）、データ保存先フォルダ（絶対パス指定）、ポート番号などを設定します。
設定完了後、`bin/` へ自動的に単一バイナリがパッケージング出力されます。

### 2. 開発モード起動
```bash
npm run dev
```
ブラウザで `http://localhost:3000` を開いて WBSer を利用できます。

### 3. 単一バイナリビルド
```bash
npm run build:exe
```
`bin/` ディレクトリに環境依存ゼロのネイティブ単一バイナリ（`wbser-macos-arm64`, `wbser-win.exe` 等）が出力されます。ダブルクリックで即座に起動可能です。

---

## ⚙️ 動作モード (Operating Modes)

| モード | 説明 |
| :--- | :--- |
| **`P2P` (分散モード)** | LAN内の仲間と同一のデータフォルダ（`data/` または共有パス）を参照し自律動作。 |
| **`CLIENT` (クライアントモード)** | 指定したホスト端末のアドレス（例: `192.168.1.50:3000`）に直接接続。 |
| **`HOST` (ホストモード)** | 自端末をホスト親機として起動し、接続を受け付ける。 |

## 📁 データ保存 ＆ ディレクトリ構造

- **保存ファイル**:
  - `state.json`: 現在のタスク状態スナップショット
  - `events.jsonl`: 不可変なイベントログ変更履歴
- **データパス自動解決**:
  - デフォルト保存先は `data/` フォルダ（絶対パス解決）。
  - `config.json` や CLI 引数 `--data-dir` にネットワーク共有フォルダや任意の絶対パスを指定可能。
- **除外設定**:
  - データの誤コミットを防ぐため、`data/*.json`, `data/*.jsonl`, `.wbser_data/`, `config.json` は `.gitignore` で保護されています。
