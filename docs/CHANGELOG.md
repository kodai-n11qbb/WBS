# 11.3 仕様変更履歴 (CHANGELOG.md)

[ドキュメントインデックスへ戻る](./index.md)

---

本ドキュメントは、WBSer の仕様策定および機能改善の履歴を記録する変更履歴です。

---

## [v1.10.0] - 2026-09-24

### 追加
- **外部データファイル改変自動検知・リアルタイム反映機能 (Live Watcher & Hot Reload)**:
  - 外部プロセスや別ユーザー、共有ストレージ等により `data/` 内の `events.jsonl` や `state.json` が追記・変更・置換された際、OSのファイルシステムイベント（`fs.watch`）およびデバウンス処理により自動検知。
  - 新規イベントの重複排除取り込み・状態再集約を行い、WebSocket経由で前面グラフキャンバスおよびガントチャートへ即座にリアルタイム反映。

---

## [v1.9.0] - 2026-09-24

### 追加
- **ノードダブルクリック最上部頂点化 ＆ サブツリー限定表示 (Double-Click Subtree Focus View)**:
  - ノードダブルクリック時、親が存在する場合はクリックした要素を画面最上部のルートノードとして配置し、そこから上方向へと接続線を伸長描画。
  - 画面上をクリックされたノードと配下の子要素群のみが存在するかのように絞り込み描画。
- **サブツリー基準の相対ネスト階層表示切替 (Relative Subtree Nest Filtering)**:
  - コントローラーのネスト表示切替（1階層 | 2階層 | すべて）を、絞り込み表示中のサブツリー配下要素に対して相対的に適用。
- **インスペクターノード干渉・重なり防止 (Inspector Shielding & Layout Isolation)**:
  - タスク選択・クリック時に詳細インスペクターパネル周辺の子要素ラベルやリンクが重なって隠してしまう問題を、物理反発フィールド拡張およびZ-index描画保護により防止。

---

## [v1.8.0] - 2026-09-23

### 変更
- **データ共有・ディレクトリ絶対パス指定仕様**:
  - 共有データ（`state.json`, `events.jsonl`）の保存先を、ターミナル目線で可視・アクセスしやすい標準フォルダ（`data/`）および絶対パス（`path.resolve()`）での解決・保存仕様に整理。
  - 単一バイナリ内の初期データ埋め込み（VFS読み取り専用）と動的永続化ストレージの役割分担を明確化。

---

## [v1.7.0] - 2026-09-23

### 追加
- **アプリ正式名称変更**: プロジェクト名称を **WBSer** に更新。
- **端末単位 Undo (1つ戻す) 機能**:
  - 自端末（`authorNodeId`）が実行した直前のアクション（作成・編集・削除）を取り消す `UNDO_ACTION` イベント発行＆状態復元メカニズムを実装。
- **進行中 (IN_PROGRESS) ステータス時の完了予定日必須化**:
  - ステータスを `IN_PROGRESS` に設定する際、完了予定日（`dueDate`）の入力をドメインバリデーション ＆ UI ダイアログにて強制化。
- **Graph View 視覚的親表示・最上部焦点移動 ＆ 左上親ナビゲーションUI**:
  - ノードクリック時、親要素との接続（上方向リンク発光）を視覚的に示しつつ、クリックノードを最上部へ自動焦点移動し配下全子要素を展開。
  - 左上に `position: absolute` の親ナビゲーションパネル（`← 親要素へ移動: [親名]`）を設置。
- **隠しデータ保存ディレクトリ互換性 (`./.wbser_data`)**:
  - 既存の `./.wbser_data` フォルダに対する自動フォールバック検出互換性を保持。
- **ガントチャート親完了予定日超過赤表示 ＆ ヘッダー幅一致修正**:
  - 子タスクの完了予定日が親の完了予定日を超過している場合、差分期間を赤くハイライト描画し「`+N日遅延`」の警告バッジを表示。
  - `gantt-ticks-header` のグリッド幅を `gantt-bar-cell` と完全に同等化。
- **3子要素以上削除時の理由ログ必須化**:
  - 3つ以上の子要素を持つ親タスク削除時、10文字以上の理由入力ダイアログを表示し、`TASK_DELETED` イベントの `reason` プロパティへ記録。

## [v1.6.0] - 2026-09-23

### 追加
- グラフビューに **Sugiyama風レイヤード・ツリー自動配置アルゴリズム (Sugiyama Untangled Tree Layout)** を導入。
- **ネスト数による縦方向自動スケール (Dynamic Y Ratio Scaling)**: 可視タスクの最大ネスト数に応じた縦幅自動均等分割。
- **焦点要素の最上部昇降アニメーション (Focal Elevation)**: 臨界減衰物理の適用。
- **文字サイズ選択機能 (Text Size Selector)**: コントローラーから文字サイズ切り替え。
