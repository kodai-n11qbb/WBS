# WBSer - Local-First WBS & Schedule Tracker

![WBSer デモ](./docs/assets/WBS.gif)

> **「WBSをみんなで作り、共有する。その副産物としてガントチャートができる。」**
> 
> エンジニア、デザイナー、PM、企画など、それぞれの役割でWBS（タスク分解・構造化）を自律的に行い、リアルタイムに統合共有。  
> 「誰が何をしていて、次に誰が何を判断すべきか」がひと目で把握でき、**進捗確認や意思決定のヒアリング負荷を劇的に削減**するローカルファーストのプロジェクト進行管理ツールです。

---

## 💡 コアコンセプト：何ができるか

従来のタスク管理ツールでは「ガントチャートを作ること」が目的化して入力が重くなり、カンバンでは全体の親子階層や依存関係が見失われがちでした。  
WBSer は、まず**チーム全員でタスクを出し合い、構造化（WBS）すること**に特化しています。

### 1. 思考を広げる全体グラフ（Obsidian風ノードグラフ）
思いついたタスクを下部入力バーから次々に入力し、ドラッグ＆ドロップで直感的に親子関係（ツリー）を構築。物理バネ演算とレイヤード配置により、複雑な依存関係も交差することなく美しく可視化されます。

![全体グラフ表示](./docs/assets/overview.png)

### 2. 日付への展開（副産物としてのガントチャート）
ノードをクリックするだけで、タスクが完了予定日に応じた4つのゾーンへ自然に整列します。

- **📅 期日未設定**: 左側の専用待機列に常駐
- **◀ 過去**: 期限超過タスクをスタック表示（赤色ハイライト ＆ 遅延バッジ）
- **タイムライン**: 本日・土日ハイライト付きの日次カレンダーグリッド（7/14/30/60日）
- **未来 ▶**: 画面外の未来タスクを右側に保持

日付列へドラッグ＆ドロップするだけで期日を直感変更でき、画面上部へドラッグすれば親タスクから切り離してルート要素へ昇格できます。

![タイムライン表示](./docs/assets/timeline.png)

### 3. Googleスプレッドシート自動同期（外部報告・共有の自動化）
ツールバーの「📊 スプシ連携」から1分で設定完了。タスク更新を検知すると、最新のガント行列（縦軸ツリー × 横軸日程）をGoogleスプレッドシートへ自動プッシュ送信します。

- **完全無料（0円）**: Google Apps Script (GAS) Webhook を採用。GCP設定やAPI課金は不要。
- **負荷ゼロ・0.1秒未満**: WBSer側で書式・色を一括計算し、GAS側は1発の流し込みで完了。
- **他シート完全保護**: スプレッドシート内の「**WBS**」という名前のシートのみを特定・自動生成して更新。既存の他タブ（議事録や集計データ）は一切改変・削除しません。

### 4. 完全ローカル完結 ＆ ゼロコンフィグ (Local-First)
- クラウドへのアカウント登録や外部サーバー接続は不要。
- データは手元の `./WBS_data/` 配下にミリ秒単位で安全に永続化されます。
- グラフ静止時は描画ループが自動停止し、アイドル時の CPU 使用率は 0% です。
- 初回起動時も本日基準のサンプルWBSが自動生成されるため、導入直後からすぐに体験できます。

### 5. チーム協業 ＆ 端末単位Undo
同一LAN内のP2P通信、または共有フォルダ（Dropbox, NAS, Git等）経由での非同期同期に対応。他のメンバーの作業を巻き込むことなく、**「自端末の直前操作のみ」を取り消せる安全なUndo機能**を備えています。

## 🎯 どうなって欲しいか（目指す体験とゴール）

- **役割ごとのWBS自律推進**:
  エンジニアは開発タスク、デザイナーはUI/アセット、PMはマイルストーンをそれぞれのレイヤーで自律的にWBS化し、1つの統合ツリーとして共有します。
- **意思決定・進捗確認の負荷削減**:
  「このタスクはどうなってる？」「誰がボールを持っている？」という定例ミーティングやチャットでの進捗ヒアリングを根絶。関係者全員が最新状況とボトルネックを即座に把握し、次の意思決定に素早く集中できる環境を作ります。

## 🚀 クイックスタート

### 開発環境での起動

Node.js 18 以上が必要です。

```bash
# 1. リポジトリをクローン
git clone https://github.com/kodai-n11qbb/WBS.git
cd WBS

# 2. 依存パッケージをインストール
npm install

# 3. 開発サーバーを起動
npm run dev
```

起動後、ブラウザで `http://localhost:3000` を開きます（自動オープン対応）。

### 対話型セットアップ
動作モード（P2P / HOST / CLIENT）やデータ保存先ディレクトリ、ポート番号を対話形式で設定できます。
```bash
npm run setup
```

### 単一バイナリのビルド (配布用)
Node.js 不要でダブルクリック起動できるネイティブ実行可能ファイル（Windows `.exe` / macOS用）をビルドします。
```bash
npm run build:exe
```
出力先: `bin/wbser`（または `bin/wbser.exe`）

## 🕹️ 主な操作方法

| 操作 | 内容 |
| :--- | :--- |
| **タスク入力バー (下部)** | タスク名を入力して `Enter` で即時作成（親タスク指定も可能） |
| **ノード クリック** | 詳細インスペクターを開き、タイムライン表示（ガント）へ切り替え |
| **ノード ダブルクリック** | 選択したタスクの配下（サブツリー）のみに絞り込み |
| **ノード ドラッグ** | カレンダー日付列へのドロップで期日変更 / 画面上端へドロップでルート昇格 |
| **キャンバス ドラッグ / ホイール** | タイムラインの横移動（過去・未来方向のスクロール） |
| **階層 (1 / 2 / 3 / すべて)** | 画面上部で表示するツリーの深さをワンクリック切り替え |
| **表示日数 (7 / 14 / 30 / 60日)** | タイムラインの表示期間を変更 |
| **文字 (小 / 中 / 大)** | ノードラベルの文字サイズを変更 |
| **↺ 戻す (Undo)** | 自端末が行った直前の操作（作成・移動・削除等）を安全に取り消し |
| **📊 スプシ連携** | Google Apps Script URLを登録し、Googleスプレッドシートへガント自動同期 |
| **🌙 / ☀️** | ダークモード / ライトモードの切り替え |

## 📊 Googleスプレッドシート連携の手順 (1分で完了)

1. 新規または既存のGoogleスプレッドシートを開く。
2. メニューの **[拡張機能] → [Apps Script]** を開く。
3. WBSer上部ツールバーの **[📊 スプシ連携]** をクリックし、**[📋 GASコードをコピー]** を押して貼り付けて保存。
4. 右上の **[デプロイ] → [新しいデプロイ]** を選択：
   - 種類の選択: 「ウェブアプリ」
   - 次のユーザーとして実行: 「自分」
   - アクセスできるユーザー: 「全員」
5. 発行された **ウェブアプリURL** をWBSerのモーダルに貼り付けて「設定を保存」。
6. 以降、タスク変更時にスプレッドシートの **「WBS」** シートへ自動で最新ガント表が反映されます。

## 📂 データ管理

- **`./WBS_data/state.json`**: 現在のタスク状態（ツリー階層構造、ステータス、完了予定日）
- **`./WBS_data/events.jsonl`**: 全変更履歴を追記保存するイベントログ
- `config.json` や CLI 引数 `--data-dir <path>` で保存先フォルダを任意に変更できます。
- 個人データや業務タスクがGitに混入しないよう、`./WBS_data/` は `.gitignore` で保護されています。
