# 01. 概念とユースケース

[インデックスへ戻る](./index.md)

---

## 1. 全体概要
本システムは、中央サーバーを必要とせず、同一ローカルエリアネットワーク (LAN) 内に存在する端末同士が直接通信（P2P）することで、プロジェクトの進捗・タスク状態・アクティビティを共有・管理するためのツールです。

**「Local-First（ローカルファースト）」** 設計思想、**「Obsidian型ノードグラフ表示 (Obsidian-like Graph View)」**、および **「Gitライクな追跡ログ (JSONL Append-Only Log)」** を採用しており、美しい視覚的ノードネットワークと爆速操作を実現します。

---

## 2. ビジュアル表現モード ＆ ChatGPT風タスク入力プロンプト

本ツールでは、複雑な項目入力を廃止したミニマル設計を基礎とし、ChatGPT 風の直感的なプロンプトバーと用途に合わせた **3つのビジュアル表現モード** を提供します。

```
+-----------------------------------------------------------------------------------------+
|  [📁 ルートタスク ▾]   タスク名を入力してEnter... (カード間ドロップで親子化可能)        ( ↑ )   |
+-----------------------------------------------------------------------------------------+
                                         |
     +-----------------------------------+-----------------------------------+
     |                                   |                                   |
     v                                   v                                   v
【1. 樹状ツリービュー (Tree View)】  【2. Obsidian型グラフビュー (Graph)】 【3. カンバンビュー (Kanban)】
・TODO/PROGRESS/DONEの区分けを排除  ・暗闇に浮かぶノードネットワーク    ・従来の 3カラムレイアウト
・単一キャンバス上で純粋なツリー表示  ・ノードの物理ドラッグ（引っ張り）  ・親タスクは上部サマリー配置
・親進捗率(`66%`) + 🔒自動算出表示   ・ノード選択でカンバン側フォーカス ・末端タスクのみアクション
・全階層ステータスバッジ直接操作    ・4秒無操作で背景スクリーンセーバー ・画面クリックで即時復帰
```

### (1) ChatGPT風タスク追加プロンプトバー (Floating Prompt Input Bar)
- **ChatGPT風の洗練されたUI**: 画面下部に浮遊する丸みを帯びたコンテナ (`border-radius: 24px`, ガラスモフィズム, フォーカス時の発光エフェクト)。
- **インライン親タスク指定**: バー左端に `📁 ルートタスク ▾` ピルタグを内包し、ワンタップで親子関係を選択してタスク作成。

### (2) 樹状ツリービュー (Pure Tree View)
- **カラム分割の排除**: ツリー表示時は TODO / PROGRESS / DONE の 3カラム区分けを廃止し、**単一キャンバス上で純粋な親・子・孫の樹状構造** として美しく描画します。
- **親タスクのステータス自動算出とロック**: 親タスクは `🔒 自動算出 (完了度 66.7%)` ＋ プログレスバーを表示。末端タスクには `[TODO]` `[PROGRESS]` `[DONE]` バッジが表示されダイレクト操作が可能。

### (3) Obsidian型インタラクティブノードグラフビュー (Obsidian Graph & Screensaver)
- **ノードの物理ドラッグ（引っ張り操作）**: Obsidian Graph 内の各ノードはマウスで自由に掴んで引き回す（物理ドラッグ）ことができ、跳ね返りや漂いのアニメーションを楽しめます。
- **ノードクリックによるフォーカス連動**: ノードをクリックすると、即座にカンバン/ツリービューの対象タスクカードへフォーカス・ハイライトが連動します。
- **無操作自動スクリーンセーバー背景移行 (Background Screensaver Mode)**: 4秒間無操作状態が続くと、Obsidian ノードグラフが `body` の背景全面で幻想的に発光し、手前の重い UI カードがフェードアウトします。**画面をクリック（またはキー操作）** すると即座に直前の編集画面へ復帰します。

### (4) カンバンビュー (Kanban View)
- TODO / IN_PROGRESS / DONE の 3カラム分割による進捗一括管理。親タスクは自動算出ロックバッジ付きで表示。

---

## 3. 解決する課題
- **区分けカラムによるツリーの分断を防止**: カラム枠を取り払い、純粋な樹状ツリーとして一覧。
- **プロジェクト全景の没入的俯瞰と操作**: 無操作時に Obsidian 型ノードグラフ背景へ自動移行し、ノードの物理ドラッグやクリック連動フォーカスで直感操作。
- **ポータブルなデスクトップバイナリ配布**: Node.js/Python 等が入っていない環境でも、単一バイナリ (`.exe` / `.app`) をダブルクリックするだけで即時起動。

---

## 4. 拡張性を担保する原則
- **ローカル優先・非同期伝播**: 変更は常にローカルの `.jsonl` ファイルへ即座に記録し、P2Pネットワークへは非同期で波及させる。
- **トランスポート透過性**: P2P 通信が UDP/TCP/WebSockets/WebRTC のいずれであっても、進行管理のドメインロジックに影響を与えない設計とする。
- **UI 非依存**: CLI、純粋ツリービュー、Obsidianグラフキャンバス、カンバンビュー等のいずれにも移植できる構造とする。
