## 1. ビジュアルデザイン哲学

WBSer は、エンジニアリングツールとしての実用性と集中を最優先とするため、**Linear / Raycast** にインスパイアされた「静かで高コントラストなテキスト主体デザインシステム」を採用しています。

- **絵文字や派手なエフェクトの排除**: 業務集中を妨げる不要なアニメーションや装飾を排除。
- **ソリッド境界線 ＆ モノトーン基調**: 視認性の高い 1px 境界線とダーク/ライトトーンの階層構造。
- **意味のあるカラーアクセント**: 状態（TODO, 進行中, 完了）および遅延警告（赤）にのみ計算されたカラーを使用。

## 3. タイポグラフィ ＆ フォントサイズ切替

- **フォントファミリ**:
  ```css
  font-family: 'Inter', -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", sans-serif;
  ```
- **文字サイズ切替 (`font-size` クラス)**:
  - **小 (Small)**: `12px` (ノードラベル `11px`) — 画面内に多くのノードを表示したい場合
  - **中 (Medium, デフォルト)**: `14px` (ノードラベル `13px`) — 標準的な可読性
  - **大 (Large)**: `16px` (ノードラベル `15px`) — プレゼンテーション・高解像度ディスプレイ向け

---

## 4. コンポーネントスタイル規約

- **角丸 (`border-radius`)**:
  - ボタン・入力欄: `6px`
  - カード・モーダル: `10px`
  - ノードピル: `9999px` (完全な丸み)
- **物理ノードラベルの保護 (Label Plate)**:
  - グラフ上のノードタイトル文字が背後の接続線と重なって読みにくくなるのを防ぐため、文字背後に背景色と同色の半透明プレート（パディング `2px 6px`）を描画。
