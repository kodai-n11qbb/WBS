## 1. 画面基本レイアウト

WBSer は、全画面（`100vh`・スクロールなし）を最大限に活用した Obsidian型物理グラフキャンバスに完全特化したシングルビュー構成となっています。
従来の独立ヘッダーバーおよびガントチャート画面を廃止し、統合上部ツールバー・全画面キャンバス・ドック型インスペクター・下部タスク入力バーのシームレスな4層構造で構成されます。

```
+-----------------------------------------------------------------------------------------+
| [WBSer] [Node: dev-1] [↺] | [ネスト: 1階層|2階層|すべて] [表示日数: 7日|14日|30日|60日] [小|中|大] [🌙/☀️] |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|  【要素クリック時: 選択ツリーのみ表示 ＆ 日付軸タイムライン (100vhフルスクリーン)】          |
|  [ 📅 期日未設定 ] [ ◀ 過去 ] [ 今日 10/17 ──── +7日 ──── +14日 ──── +30日 ] [ 未来 ▶ ]    |
|     (Zone 1)        (Zone 2)                (メインタイムライン)         (Zone 4)       |
|                                                                                         |
|        ◯ (未設定)       ◯ (過去)        ◯──[タスクA (右側配置ラベル)]                           |
|         : (波線Bézier)   : (波線Bézier)  │                                               |
|         :                :              ◯──[同日タスクB (同一X軸・縦積み)]                      |
|                                                                                         |
|  ※ 画面端やキャンバスを左ドラッグ(Pan)した際は、過去日(10/15, 10/16等)もタイムライン軸上に展開   |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
| [インスペクタードック: #obsidian-inspector] (入力バーの上に固定ドック・キャンバスに被らない) |
| [タイトル編集] [完了予定日:YYYY-MM-DD] [TODO/進行中/完了] [ルート化] [タスク削除] [✕]    |
+-----------------------------------------------------------------------------------------+
| [下部固定 タスク追加バー: #task-input-section]                                           |
| [ 親タスク選択 ▾ ]  タスク名を入力してEnter...                                  [ 作成 ] |
+-----------------------------------------------------------------------------------------+
```

## 2. 主要コンポーネント配置

### (1) 統合トップツールバー (`.graph-top-toolbar`)
画面最上部に常設される高さ `42px` の極薄ガラスモーフィズムバー。従来の `.app-header` を統合し、キャンバスの作業領域を垂直方向に最大限拡張。
- **左側エリア**:
  - `project-title`: ミニマルロゴ（`WBSer`）
  - `node-pill`: 自端末のP2P/ローカル接続状態（`Node: dev-node-1`）
  - `btn-undo`: 直前操作の取り消し `[ ↺ 1つ戻す ]` ボタン
- **右側エリア (`#depth-filter-control`)**:
  - **ネスト表示切替**:
    - 要素未選択時: ルート起点の階層深度（1階層 / 2階層 / 3階層 / すべて）。
    - 要素選択時: **クリックされた要素を起点とした相対階層絞り込み**（選択要素自身＋直下1階層 / 2階層 / 3階層 / すべて）。
  - **表示日数切替（要素選択時アクティブ）**:
    - タイムライン日数設定ボタン（`[ 7日 ] [ 14日 ] [ 30日 ] [ 60日 ]`）。
  - **文字サイズ切替**: 小 / 中 / 大。
  - **テーマ切り替え (`btn-theme-toggle`)**: ダーク / ライトモード切り替えボタン。

### (2) 全画面物理グラフキャンバス (`#obsidian-graph-view` / `.canvas-wrapper`)
- `height: 100vh` レイアウト内で `flex: 1` として画面の残りの高さを縦横いっぱいに使用。
- **自動リサイズ同期 (`ResizeObserver`)**: ウィンドウサイズ変更時に即座にキャンバスの幅・高さを同期更新し、再クリックなしで描画を自動最適化。
- **キャンバス内ルート化ドロップゾーン (`#root-dropzone`)**:
  - ノードをキャンバス上部（`Y <= 60px`）へドラッグすると、ガイド枠が点灯。ドロップでルートタスクへ昇格。

### (3) 要素選択時 日付軸タイムライン ＆ 過去日ダイナミック配置
- **選択ツリー以外のノード完全非表示**:
  - ノード選択時は、選択要素とその子孫タスクのみを描画。半透明の背景ノードは完全に非表示とし、視覚的ノイズをゼロ化。
  - 空白クリックやインスペクター閉じるボタンで、全体グラフへ瞬時に復帰。
- **過去タスクの日付列配置（表示範囲内）**:
  - 過去の完了予定日を持つタスクであっても、現在タイムライン軸に表示されている日付範囲（キャンバスを左Panして過去日を表示した場合を含む）に入っていれば、**その日付自体の列（X座標）に配置**。
  - タイムライン軸の最左端日付よりもさらに古いタスクのみ、左側の「Zone 2: ◀ 過去」ゾーンへ集約配置。
- **ラベルの右側配置（タイムラインモード）**:
  - タイムラインモード時は、ノードサークルの右横（`X + radius + 10px`）に左揃えでタイトルラベルを描画。
  - 同一完了予定日を持つ複数タスクが同一X軸に縦積みされても、上下のノードとテキストが重ならないクリアな視認性を実現。

### (4) ドック型インスペクターパネル (`#obsidian-inspector`)
- キャンバス中央への浮動オーバーレイ配置を廃止し、最下部のタスク入力バーの直上にドック（Dock）配置。
- キャンバス内のノードや接続線に覆い被さることなく、安全にタイトル編集・完了予定日変更・ステータス更新・削除を実行可能。

### (5) 最下部固定 タスク追加バー (`#task-input-section`)
- 画面最下部に常設。親タスク選択・タスク名入力・Enter即時作成をサポート。
- 親タスクのドロップダウン選択、タスク名テキスト入力、Enterキーでの即時追加をサポート。
