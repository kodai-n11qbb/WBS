# Share-Log プロジェクト仕様ドキュメント インデックス

本ドキュメント群は、分散・ローカルファーストタスク管理システム **「Share-Log」** の概念、システムアーキテクチャ、データモデル、同期仕様、および拡張設計を定義する技術仕様書です。
開発方針については [`../DEV_POLICY_v1.0518.md`](../DEV_POLICY_v1.0518.md) を厳守します。

---

## ドキュメント構成

1. [01. 概念とユースケース](./01_concept.md)
   - 本システムのコアコンセプト、Obsidian型ノードグラフ前面配置（初期配置絡まり防止・サブツリー強調・文字重なり防止・キャンバス空白クリック解除）、GanttProjectスタイルガントチャート（副タイトル削除・完了予定日マーカードラッグ）、動作モード（P2P / CLIENT / HOST）、解決する課題
2. [02. システムアーキテクチャ抽象](./02_architecture.md)
   - Hexagonal / Clean Architecture に基づくレイヤー構造とコンポーネントポート定義、DI（依存性注入）方針、スタンドアロン単一バイナリ構造
3. [03. データモデルと同期仕様](./03_data_sync.md)
   - ミニマルタスクエンティティ、`data/state.json` スナップショット仕様、`config.json` スキーマ、対話型セットアップCLI、イベントログ同期 (`events.jsonl`) メカニズム
4. [04. 拡張性およびプラグイン設計](./04_extension_spec.md)
   - 単一バイナリ配布パッケージング、対話型セットアップ、通信・ストレージアダプター拡張ポイント、相対パス保守ルール

## 仕様の変更履歴

- **v1.6.0 (2026-09-23)**:
  - グラフビューに **Sugiyama風レイヤード・ツリー自動配置アルゴリズム (Sugiyama Untangled Tree Layout)** を導入。末端タスク数の再帰採寸に基づきサブツリーごとのX座標領域を非交差計算し、線の交差（クロス）や重なりを幾何学的に解消。
  - **ネスト数による縦方向自動スケール (Dynamic Y Ratio Scaling)**: 可視タスクの最大ネスト数（1〜N階層）に応じてキャンバスの縦幅を自動均等分割。ネスト数が変化しても全ての階層がキャンバス内に美しく自動収容。
  - **焦点要素の最上部昇降アニメーション (Focal Elevation)**: 要素クリック時、対象ノードおよび配下ツリー全体が画面最上部へスッと浮上し、配下タスク全体をスクロールフリーで可視化。揺れやバウンドを抑えた臨界減衰（Critical Damping）を適用。
  - **文字サイズ選択機能 (Text Size Selector)**: コントローラーから文字サイズ（小 / 中 / 大）を即座に切替可能。
- **v1.5.0 (2026-09-23)**:
  - グラフビュー初期描画時のノード絡まり防止アルゴリズム（Radial Sector Physics Layout）を導入。
  - ノードクリック時に**配下の子孫タスク群（子・孫ノード）およびリンクを強調ハイライト**し、非選択要素を半透明化（ディミング）。
  - ノードラベル文字の重なり視認性を防護する背景プレート/アウトライン描画を追加。
  - **キャンバス空白部クリックによる選択フォーカス解除（初期状態復帰）**をサポート。
  - ガントチャートヘッダー下の不要な副タイトルテキストを削除。
- **v1.4.0 (2026-09-23)**:
  - グラフビューのネスト表示デフォルトを「**すべて (`'all'`)**」に変更。
  - ガントチャートの完了予定日マーカー (`🚩`) を**ドラッグ＆ドロップで直接掴んで離して操作・完了予定日更新**できるインタラクティブ機能を追加。
- **v1.3.0 (2026-09-22)**:
  - 画面仕様を **グラフ ＆ ガント の 2ビュー構成** に特化。
  - 親タスク設定確認ダイアログでの **Enter（確定）/ Esc（キャンセル）** キーボードショートカット操作に対応。
  - 表記を「**完了予定日**」に統一。
  - 初回デモサンプルデータを3ヶ月（90日）スケールに拡張し、ガントチャートで一番遠い完了予定日 (`dueDate`) を自動判定してタイムライン右端内に納める Auto-Fit スケール描画を導入。
- **v1.2.0 (2026-09-22)**:
  - Linear / Raycast スタイルテキストデザインシステム（Dark/Lightモード）を導入。
  - Obsidian Node Inspector およびキャンバス内最上部ルート化ドロップゾーンを追加。
  - 不変イベントログからの不完全作業期間プロット型ガントチャートを導入。
- **v1.1.0 (2026-09-22)**:
  - 3つの動作モード（P2P / CLIENT / HOST）と `config.json` スキーマ仕様を追加。
  - ディレクトリ直下への最新状態スナップショット (`data/state.json`) 保存仕様を策定。
- **v1.0.0 (2026-09-20)**:
  - ローカルファースト P2P タスク同期ツールの基本仕様を策定。
