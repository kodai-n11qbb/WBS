# 01. 概念とユースケース

[インデックスへ戻る](./index.md)

---

## 1. 全体概要
本システムは、中央サーバーを必要とせず、同一ローカルエリアネットワーク (LAN) 内に存在する端末同士が直接通信（P2P）することで、プロジェクトの進捗・タスク状態・アクティビティを共有・管理するためのツールです。

**「Local-First（ローカルファースト）」** 設計思想、**「Obsidian型ノードグラフ表示 (Obsidian-like Graph View)」**、および **「ディレクトリ直下の最新状態スナップショット (`data/state.json`) ＋ Gitライク追跡ログ (`data/events.jsonl`)」** を採用しており、直感的なビジュアル操作と高速読み込みを実現します。

---

## 2. ビジュアル表現モード ＆ 下部固定 ChatGPT風プロンプトバー

本ツールでは、複雑な項目入力を廃止したミニマル設計を基礎とし、画面下部に固定される ChatGPT 風の直感的なプロンプトバーと用途に合わせた **3つのビジュアル表現モード** を提供します。

```
+-----------------------------------------------------------------------------------------+
|                      画面下部固定 ChatGPT風タスク追加プロンプトバー                       |
|  [📁 ルートタスク ▾]  タスク名を入力してEnter... (カード間ドロップで親子化可能)        ( ↑ )   |
+-----------------------------------------------------------------------------------------+
                                         |
     +-----------------------------------+-----------------------------------+
     |                                   |                                   |
     v                                   v                                   v
【1. 樹状ツリービュー (Tree View)】  【2. Obsidian型グラフビュー (Graph)】 【3. カンバンビュー (Kanban)】
・画面上を優しく漂う独立ルートタスク ・暗闇に浮かぶノード物理ネットワーク・全ルートタスクがTODO内に自然配置
・コネクタ線付きの洗練された階層   ・バネ物理（ドラッグ時に他ノードが連動）・縦スクロール＆間隔の統一UX
・カード背景グラデーション進捗表示  ・枠内ドロップで即座に親子化     ・ステータスボタン/キーボード操作
・全階層ステータスバッジ直接操作   ・ノードクリックで該当カードフォーカス ・DND無効化による誤操作防止
```

### (1) 画面下部固定 ChatGPT風プロンプトバー (Bottom Fixed Floating Prompt Bar)
- **画面下部への固定配置**: 画面最下部に `position: fixed` で常時浮遊表示される ChatGPT 風の丸みのある入力バー (`border-radius: 24px`, ガラスモフィズム, フォーカス発光)。
- **直接ルートタスク作成**: 親を指定せずに作成したタスクは、自動生成される「未分類」コンテナには入らず、**そのまま独立したルートタスク (`parentId: null`) として生成** されます。バー左端のピルで特定の親タスクを選択することも可能です。

### (2) 画面自由浮遊カード ＆ 樹状ツリービュー (Screen-Floating Cards & Pure Tree View)
- **画面上を漂う独立ルートタスクカード**:
  - 親を持たない独立ルートタスクは、画面上の空きスペースを優しく漂う発光フローズンカード (`.floating-unclassified-card`, `@keyframes ambientFloat`) として個別に描画。
  - マウスで掴んでツリー表示内の任意の親タスク枠内へドラッグ＆ドロップ（**「↙ 子要素として追加」** ガイド表示）することで、直感的に子タスク化。
- **タイトル背景グラデーションによる進捗表示**:
  - 縦スペースを消費していた独立プログレスバーを廃止し、親タスクカードの背景 (`linear-gradient`) に直接、子タスクの完了率（%）に応じたグラデーションバーを描画。
  - タイトル横に `1/3 (33%)` 形式のコンパクトな進捗バッジを表示し、ツリー全体の縦幅と視認性を格段に向上。

### (3) Obsidian型物理グラフィカルキャンバス (Obsidian Spring Physics Canvas)
- **バネ物理 (Spring Elasticity) による滑らかな連動**: ノードをドラッグした際、接続されている他のノードがバネのように引きずられて連動・追従する物理シミュレーション。
- **ノードの枠内ドロップ親子化**: どの状態のノードからでも、他のノードの円盤枠内（半径45px以内）にドラッグ＆ドロップすることで、確認ダイアログ経由で即座に親タスクを変更（※循環参照防止機能付き）。
- **ノードクリックフォーカス同期**: ノードをクリックすると、直ちにツリー/カンバン表示の該当タスクカードへフォーカス・スクロール移動。

### (4) カンバンビュー (Kanban View - 統一縦ナビゲーション ＆ TODO統合)
- TODO / IN_PROGRESS / DONE の 3カラム分割による進捗一括管理。
- **ルートタスクのTODOカラム統合**: ルートタスクも特別な枠を設けず、通常のTODOアイテムとして「To Do」カラム内に自然に並べて表示。
- **誤操作防止のDND無効化 ＆ ボタン/キーボード操作**: カンバン上ではドラッグ＆ドロップを無効化し、`[未着手] [進行中] [完了]` ボタンおよびキーボード `←` / `→` 操作でステータス変更。

## 3. ディレクトリ直下の最新状態スナップショット運用 (`data/state.json`)
- **最新情報の単一ファイル管理**:
  - タスクの追加・変更・削除のたびに、指定ディレクトリ内の `data/state.json` に最新の全タスク状態（Materialized Snapshot）がリアルタイム自動保存されます。
  - 外部スクリプトや他ツール連携時にも、`data/state.json` を開くだけで今現在の全タスク状態が一目で把握可能です。
- **背景履歴ログ (`data/events.jsonl`)**:
  - P2Pネットワーク同期や過去履歴の復元用として、不可変なイベント変更履歴をあわせてバックグラウンド管理。

---

## 4. 統一された縦方向（上下）キーボードナビゲーション ＆ 単一親タスク設計
- **視覚的DOM順序キーボード操作**:
  - `↓` / `↑` キーを押すと、内部配列順ではなく画面上で見た通りに上から下／下から上へとフォーカスが移動。
  - カンバン表示中、`←` / `→` キーで隣のカラムへフォーカス移動。
- **単一親タスク（Single-Parent Tree Architecture）**:
  - 各タスクが持てる親は一般的な1:Nツリー構造に従い **最大1つ** (`Task.parentId?: string | null`) を厳守。

---

## 5. 解決する課題
- **ツリーの分断と縦スペースの浪費を防止**: カード背景進捗 fill と浮遊カードにより、コンパクトで洗練されたツリー表示を実現。
- **直感的な親子化と誤操作防止**: 枠内ドロップでの子要素化ガイドと、カンバンビューでのDND無効化による安定したUX。
- **最新状態の可視性と高速起動**: `data/state.json` スナップショットにより、最速起動と外部連携を実現。
- **ポータブルなデスクトップバイナリ配布**: Node.js/Python 等が入っていない環境でも、単一バイナリ (`.exe` / `.app`) をダブルクリックするだけで即時起動。

---

## 6. 拡張性を担保する原則
- **ローカル優先・非同期伝播**: 変更は常にローカルの `data/state.json` および `.jsonl` ファイルへ即座に記録し、P2Pネットワークへは非同期で波及させる。
- **トランスポート透過性**: P2P 通信が UDP/TCP/WebSockets/WebRTC のいずれであっても、進行管理のドメインロジックに影響を与えない設計とする。
- **UI 非依存**: CLI、純粋ツリービュー、Obsidianグラフキャンバス、カンバンビュー等のいずれにも移植できる構造とする。
