## 1. 画面基本レイアウト

WBSer は、全画面（`100vh`・スクロールなし）を最大限に活用した Obsidian型物理グラフキャンバスに完全特化したシングルビュー構成となっています。
従来の独立ヘッダーバーおよびガントチャート画面を廃止し、統合上部ツールバー・全画面キャンバス・ドック型インスペクター・下部タスク入力バーのシームレスな4層構造で構成されます。

```
+-----------------------------------------------------------------------------------------+
| [WBSer] [Node: dev-1] [↺] | [ネスト: 1階層|2階層|すべて] [表示日数: 7日|14日|30日|60日] [小|中|大] [🌙/☀️] |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|  【要素クリック時: 選択ツリーのみ表示 ＆ 日付軸タイムライン (100vhフルスクリーン)】          |
|  [ 📅 期日未設定 ] [ ◀ 過去 ] [ 今日 10/18 ──── +7日 ──── +14日 ──── +30日 ] [ 未来 ▶ ]    |
|     (Zone 1)        (Zone 2)                (メインタイムライン)         (Zone 4)       |
|                                                                                         |
|        ◯ (未設定)       ◯ (過去)        ◯──▶ [タスクA (下側配置ラベル)]                         |
|         │                │              │                                               |
|         └────────────────┼──────────────◯──▶ [同日タスクB (同一X軸・縦積み)]                    |
|                          └──────────────┘ (直線の親→子エッジ ＆ 矢印)                     |
|                                                                                         |
|  ※ 画面端やキャンバスを左ドラッグ(Pan)した際は、過去日(10/15, 10/16等)もタイムライン軸上に展開   |
|  ※ マウスカーソルが接近したノード＆ラベルを最前面（z軸トップ）に動的ソート描画                     |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
| [インスペクタードック: #obsidian-inspector] (入力バーの上に固定ドック・キャンバスに被らない) |
| [タイトル編集] [完了予定日:YYYY-MM-DD] [TODO/進行中/完了] [ルート化] [タスク削除] [✕]    |
+-----------------------------------------------------------------------------------------+
| [下部固定 タスク追加バー: #task-input-section]                                           |
| [ 親タスク選択 ▾ ]  タスク名を入力してEnter...                                  [ 作成 ] |
+-----------------------------------------------------------------------------------------+
```

## 2. 主要コンポーネント配置

### (1) 統合トップツールバー (`.graph-top-toolbar`)
画面最上部に常設される高さ `42px` の極薄ガラスモーフィズムバー。従来の `.app-header` を統合し、キャンバスの作業領域を垂直方向に最大限拡張。
- **左側エリア**:
  - `project-title`: ミニマルロゴ（`WBSer`）
  - `node-pill`: 自端末のP2P/ローカル接続状態（`Node: dev-node-1`）
  - `btn-undo`: 直前操作の取り消し `[ ↺ 1つ戻す ]` ボタン
- **右側エリア (`#depth-filter-control`)**:
  - **ネスト表示切替**:
    - 要素未選択時: ルート起点の階層深度（1階層 / 2階層 / 3階層 / すべて）。**初期デフォルトを「2階層」に設定**（全タスク展開による画面右端での密集スタックを防止し、ルート＋主要ブランチをスッキリ俯瞰）。
    - 要素選択時: **クリックされた要素を起点とした相対階層絞り込み**（選択要素自身＋直下1階層 / 2階層 / 3階層 / すべて）。
  - **表示日数切替（要素選択時アクティブ）**:
    - タイムライン日数設定ボタン（`[ 7日 ] [ 14日 ] [ 30日 ] [ 60日 ]`）。
  - **文字サイズ切替**: 小 / 中 / 大。
  - **テーマ切り替え (`btn-theme-toggle`)**: ダーク / ライトモード切り替えボタン。

### (2) 全画面物理グラフキャンバス (`#obsidian-graph-view` / `.canvas-wrapper`)
- `height: 100vh` レイアウト内で `flex: 1` として画面の残りの高さを縦横いっぱいに使用。
- **自動リサイズ同期 (`ResizeObserver`)**: ウィンドウサイズ変更時に即座にキャンバスの幅・高さを同期更新し、再クリックなしで描画を自動最適化。
- **全体グラフでのレイアウト保証と描画安定化 (Bounded Sugiyama Layout & 2-Tier Staggering)**:
  - Sugiyamaツリー配置のX軸座標を画面幅（`[padX, width - padX]`）内に厳密に正規化・スケーリング。階層内のタスク数が多い場合でも、画面外への突き抜けや右端へのスタックを根絶。
  - 同一階層にタスクが密集（5件以上）している場合、垂直方向（Y軸）に2段階スタッガー配置（32px垂直分離）を自動適用し、横長の日本語タスク名同士のテキスト衝突をゼロ化。
  - ラベル背景プレートの左右端に対しても画面枠クランプを適用し、画面外はみ出しゼロ（0件）を保証。
- **JS実行パフォーマンス最適化（物理スリープ・テキスト計測キャッシュ・計算メモ化）**:
  - **物理スリープ (Idle Sleep)**: 物理移動速度が閾値（`maxVelocity < 0.012`）を下回ると `requestAnimationFrame` を一時停止。待機中のCPU使用率・JS分析時間を実質0%に削減。マウス操作やデータ更新時に `wakeAnimation()` で瞬時に復帰。
  - **テキスト幅キャッシュ**: ノード生成・更新時に `titleWidth` を1度だけ計測してキャッシュ。毎フレームの pairwise ループ内で発生していた25,000回/秒超の `ctx.measureText` 呼び出しを完全排除。
  - **レイアウト計算メモ化**: ツリー探索・日付グルーピング・ソート処理をフレーム外へ移動し、状態変更時のみ差分再計算。
- **親ノードバッジクリックによる子要素折りたたみ (Branch Collapse & Expansion)**:
  - 親ノード中央の子タスク数バッジをクリックすることで、配下のブランチをアコーディオンのように開閉。作業対象外のツリーを閉じて画面を整理。
- **キャンバス内ルート化ドロップゾーン (`#root-dropzone`)**:
  - ノードをキャンバス上部（`Y <= 60px`）へドラッグすると、ガイド枠が点灯。ドロップでルートタスクへ昇格。

### (3) 要素選択時 日付軸タイムライン ＆ 過去日ダイナミック配置
- **選択ツリー以外のノード非表示 ＆ 単独要素（孤立ノード）の常駐表示**:
  - ノード選択時は、選択要素とその子孫タスクを描画し、関連のない別ツリーのノードは完全非表示として視覚的ノイズをゼロ化。
  - **単独要素（親要素も子要素もない要素）の常駐**: 親を持たず（`parentId === null`）、子要素も持たない単独要素は、期日設定の有無にかかわらず他ツリー選択中であっても常に常駐表示。期日未設定のものは画面左端の「Zone 1: 📅 期日未設定」待機列へ、期日設定済みのものはタイムライン上の該当列（または過去/未来ゾーン）へ配置され、未整理・独立タスクをいつでも視認・配置可能。
  - 空白クリックやインスペクター閉じるボタンで、全体グラフへ瞬時に復帰。
- **過去タスクの日付列配置（表示範囲内）**:
  - 過去の完了予定日を持つタスクであっても、現在タイムライン軸に表示されている日付範囲（キャンバスを左Panして過去日を表示した場合を含む）に入っていれば、**その日付自体の列（X座標）に配置**。
  - タイムライン軸の最左端日付よりもさらに古いタスクのみ、左側の「Zone 2: ◀ 過去」ゾーンへ集約配置。
- **ゾーン別・表示範囲別のラベル配置最適化 ＆ 表示トグル（目のアイコン）**:
  - **表示日付範囲内（メインタイムライン列上）**: ラベルをノード円の**下側**（`textAlign: center`）に配置。カレンダーの日付目盛りとノードが美しく整合。同日タスク縦積み時は `minDistY: 66px` および階層オフセットにより上下のテキスト重なりを防止。
  - **未来ゾーン（Zone 4: 右端）**: ラベルをノード円の**左側**（`textAlign: right`）に配置。画面右端へのはみ出しや詰まりを防止し、画面内側へ綺麗に収容。
  - **過去ゾーン（Zone 2） / 期日未設定（Zone 1: 左端）**: ラベルをノード円の**右側**（`textAlign: left`）に配置。
  - **過去・未来ゾーンのラベル表示トグル（目のアイコン / Zone Visibility Toggle）**: Zone 2「◀ 過去」および Zone 4「未来 ▶」のヘッダープレート内に目のマーク（表示: `👁` / 非表示: `👁‍🗨`）を配置。クリックで該当ゾーンのタスクタイトルラベルの表示/非表示を個別に切り替え可能。非表示時もノード円やエッジは維持され、ホバー時に一時的にラベル・ツールチップを表示。設定は `localStorage` に保存。
- **直線エッジ接続 ＆ 親子血統可視化 (Straight Edges & Lineage Visualization)**:
  - **直線の親→子エッジ (Straight Line Flow)**: 湾曲（Bézier）を廃止し、タイムラインモード・通常グラフモードの双方で親から子へ向かうシャープな直線（Straight Line）で統一接続。進行方向（60%位置）に端正な三角矢印マーカーを配置。
  - **血統ハイライト (Lineage Glow)**: ノードホバー時および選択時、直親および直子のリンク線のみを太く発光（Glow: `#f59e0b`）させ、非関連の枝を減光して親子関係を強調。
- **カーソル接近ノード＆ラベルの動的最前面表示 (Cursor Proximity Z-Ordering)**:
  - タイムライン上で同日・同深さの兄弟タスクが近接配置されている状況において、マウスカーソルが近づいた（ホバー中または最接近）ノードを**描画ループの最後（z軸最前面）**に回して描画。
  - 背景プレートとラベル文字が他の兄弟要素の背面に潜り込むことなく、手前にくっきりと浮き上がって可読性を100%保証。
- **現実味のあるデモデータセット仕様 (初回自動生成・ブートストラップ)**:
  - 起動日を起点とした「Webプロダクト新機能リリース」実務シナリオ（19件規模・複数階層・複数親依存・未設定/過去/現在/未来の全ゾーン展開）を標準搭載。適度な情報量にスリム化し、視認性と俯瞰性を両立。

### (4) 最下部コントロールエリア (`.bottom-controls-dock`)
- **ドック型インスペクターパネル (`#obsidian-inspector`)**:
  - タスク追加バーの直上にスタック配置。
  - 直下のタスク追加バーと重複（重なり）しないよう上下分離して配置。安全にタイトル編集・完了予定日変更・ステータス更新・削除を実行可能。
  - **階層パンくず表示 (Breadcrumbs)**: 選択中タスクの親パス（例: `親: [ルート] > [親タスク名]`）を常時表示し、クリックで瞬時に親タスクへフォーカスを移動可能。
- **最下部 タスク追加バー (`#task-input-section`)**:
  - 画面最下部に常設。親タスク選択・タスク名入力・Enter即時作成をサポート。
  - インスペクターが開いている際も重なることなく、インスペクターの下部に配置を維持。キャンバスの作業領域を侵害しない。
